# 主窗口的键盘区域

主窗口分成几个区域，键盘在区域之间、区域之内的走法统一（`src/keyboard_regions.{h,cpp}`）。

## 区域

按 F6 的顺序：

1. 字幕表格
2. 编辑框（样式、说话人、特效、时间、字幕文本、按钮）
3. 音频（波形）
4. 视频（画面、进度条、下方按钮）
5. 侧边栏：样式面板，文案面板显示时换成文案面板

没打开的区域跳过：没加载音频就跳过音频，没加载视频就跳过视频。侧边栏收起或隐藏时，轮到它就展开。

## 按键

- **F6 / Shift+F6**：到下一个 / 上一个区域，最后一个之后回到第一个。命令是 `app/region/next`、`app/region/previous`，可以在首选项的快捷键页里改。进入区域时键盘落在：
  - 字幕表格：表格本身；
  - 编辑框：字幕文本框；
  - 音频：波形；
  - 视频：画面；
  - 样式面板：页的切换条；
  - 文案面板：文本框。
- **Tab / Shift+Tab**：只在当前区域里转，到最后一个控件后回到第一个，不会跑进别的区域。每条工具栏停一次（见下面的[工具栏](#工具栏)），滚动条不停：它用所在窗口自己的键操作。侧边栏按它自己的顺序转（见 [样式面板](style-panel.md)）。字幕表格、波形、视频画面和进度条自己接收所有按键，没被快捷键用掉的 Tab 也按这条规则走。
  - 视频里的顺序跟眼睛看的一样：画面、进度条、下面一排从左到右（时间读数、播放按钮、选项按钮、缩放），然后是右边的可视化工具栏和它的子工具栏。相对时间读数没有可输入的东西，不停。
  - 音频里：波形、垂直缩放 / 音量、音频工具栏。
  - 编辑框里：时间|帧切换也停（字段在文本上面时，它在字幕文本框之前）。
- **Esc**：回到字幕文本框，任何区域都一样（视频的拖动预览模式下先退出拖动模式）。

以前 F6 只进出侧边栏（`app/style_panel/keyboard`）。升级时，用户快捷键里这个命令的 F6 被拿掉，F6 / Shift+F6 改给区域轮换（迁移名 `F6 regions`）；如果这两个键已被别的命令占用，就不绑定。`app/style_panel/keyboard` 命令仍在，没有默认快捷键。

## 区域里的按键

各区域原有的快捷键都不变，下面是在区域里新增的。它们都是普通快捷键，可以在首选项的快捷键页里改；已有用户升级时自动补上，某个键在它的区域里已被占用就不绑定（迁移名 `keys in regions`，第二批是 `more keys in regions`）。

键盘在视频或音频区域里的自绘控件、工具栏上时，它们自己用不到的键交给所在区域的快捷键（`regions::Region::keys`）：比如键盘在缩放控件上按 ↑ 仍然是上一行，在时间读数上按 ← 仍然是上一帧。

### 字幕表格

表格里有一个“键盘光标行”，和当前行（编辑框显示的那一行）分开。原来 Ctrl+↑/↓ 只移动当前行、不改选择，但编辑框的修改作用于选中的行，移过去以后编辑框显示的那一行其实不会被修改，容易改错；现在 Ctrl 加方向键移动的是光标行，当前行和选择都不动。

- 光标行外面画一圈强调色细框，只在表格拿着键盘时画。平时它就是当前行。
- **Ctrl+↑/↓、Ctrl+PageUp/PageDown、Ctrl+Home/End**：只移动光标行。
- **Ctrl+空格**（`grid/select/toggle`）：把光标行加进选择并设为当前行；已在选择里就移出（绑定的行组整组移出）。移出的是当前行时，当前行换到离它最近的另一条选中行。最后一条选中行不能移出。光标留在原行。
- **Shift+空格**（`grid/select/range`）：选中从扩选起点（上次不按 Ctrl 移到或点到的行）到光标行的一段，代替原来的选择，光标行成为当前行。
- **Ctrl+Shift+空格**（`grid/select/range/add`）：把这一段加进原来的选择。
- 不按 Ctrl 的 ↑/↓ 等从光标行出发移动，选中新的一行；点击也把光标行放到点的那一行。
- Ctrl+空格原来是窗口的“聚焦进度条”（`video/focus_seek`），只在表格里被这条覆盖，别的地方不变。空格在表格里仍然播放视频。

### 视频（画面、进度条）

原有的 ←/→ 逐帧、Shift 跳关键帧、Ctrl 跳到行边界、Alt 大步跳、空格播放、字母键切换工具都不变。新增：

- **↑/↓**（`video/line/prev`、`video/line/next`）：上一行 / 下一行字幕，视频跳到那一行开头。
- **Home / End**（`video/jump/start`、`video/jump/end`）：跳到当前行的开头 / 结尾。原来在进度条上它们转给表格，跳到第一行 / 最后一行。
- **R**（`video/play/line`）：播放当前行，和音频里的 R 一样。
- **Ctrl+= / Ctrl++ / Ctrl+−**（`video/zoom/in`、`video/zoom/out`）：放大 / 缩小一档（12.5%）；**Ctrl+0**（`video/zoom/100`）：100%。小键盘的 + / − 原来就有。
- **Ctrl+Shift+方向键**（`video/tool/nudge/left` 等）：把可视化工具选中的点挪 1 个脚本像素；**Alt+Shift+方向键**（`video/tool/nudge/left/large` 等）挪 10 个。见下面的[可视化工具微调](#可视化工具微调)。没有用 Ctrl+Alt+方向键：有的显卡驱动用它旋转屏幕。

### 音频（波形）

原有的 ←/→（Z / X）上一个 / 下一个时间单位、字母键播放、Enter / G 确认、C / V 加缓冲都不变。新增：

- **Shift+←/→**（`time/start/decrease`、`time/start/increase`）：开始时间提前 / 推后 10 毫秒。
- **Ctrl+←/→**（`time/length/decrease`、`time/length/increase`）：结束时间提前 / 推后 10 毫秒（和小键盘的 − / + 相同）。
- **↑/↓**（`grid/line/prev`、`grid/line/next`）：上一行 / 下一行。
- **空格**（`audio/play/toggle`）：播放 / 停止音频选区。键盘在波形上时空格不再播放视频，其他区域照旧。
- **Ctrl+= / Ctrl++ / Ctrl+−**（`audio/zoom/in`、`audio/zoom/out`）：水平放大 / 缩小一档，和滚轮的一格一样，当前行的中点留在原来的位置（它在视野里时）；**Ctrl+0**（`audio/zoom/reset`）：回到默认的水平缩放。缩放会记下来，和滚轮、滚动条的一样（`Audio/Zoom/Horizontal`）。
- **Ctrl+↑/↓**（`audio/zoom/vertical/in`、`audio/zoom/vertical/out`）：波形加高 / 压低 5 格；链接时音量跟着变。
- **Shift+↑/↓**（`audio/volume/up`、`audio/volume/down`）：音量加 / 减 5 格；链接时只有一条轨道，两个一起变，和拖它一样。

### 编辑框

- **Alt+I / Alt+R**（`edit/time_unit/time`、`edit/time_unit/frame`）：时间|帧切换选“时间” / “帧”，就是它还是单选按钮时的助记键。没有视频也没有时间码时“帧”不可用。
- 注释、对照原文勾选框上按空格切换，自绘按钮上按空格或 Enter 按下：这些键在它们自己的 `wxEVT_CHAR_HOOK` 里处理，先于编辑框的快捷键。以前空格先被编辑框拿去播放视频、Enter 拿去转到下一行，勾选框上的空格从来没起作用。样式这类自绘下拉框打开列表的空格、Enter、F4、Alt+↓ 同样先给它自己。

## 自绘控件

这几个控件是画出来的，原来只能用鼠标，现在 Tab 能停到上面。点击它们仍然不抢键盘（`AcceptsFocus` 为假，`AcceptsFocusFromKeyboard` 为真）：用鼠标时键盘还留在原来的地方。键盘在上面时画一圈强调色的框（时间读数的可编辑部分外面一圈，缩放和切换的边框变成强调色，音频轨道 / 按钮外面一圈）。

- **视频时间读数**（`VideoTimeLabel`）：Enter 或 F2 打开输入框输入时间或帧号；直接敲数字、`:`、`.`、`,` 也打开输入框，敲的字已经在里面。确认或 Esc 后键盘回到读数上，不跳到进度条（用鼠标点开的仍然回进度条）。菜单键 / Shift+F10 在读数下方弹出复制菜单。没有视频时不停。
- **视频缩放**（`VideoZoomControl`）：← 或 − 缩小一档，→ 或 + / = 放大一档；Enter、空格、F4、Alt+↓ 打开预设列表。Shift 只和 + 这类符号键一起算（很多键盘上 + 要按 Shift），Shift+→ 仍然是视频的跳到下一个关键帧。
- **音频垂直缩放 / 音量**（`AudioLevels`）：←/→ 在缩放轨道、音量轨道、链接按钮、重置按钮之间移动（链接时没有音量轨道），到头不转回去；在轨道上 ↑/↓ 一格、PageUp/PageDown 十格；在按钮上空格或 Enter 按下。在轨道上空格、Enter 还是音频的（播放、确认），在按钮上 ↑/↓ 还是音频的（换行）。
- **编辑框的时间|帧切换**（`TimeUnitToggle`）：空格或 Enter 切换，← 选时间，→ 选帧。

## 工具栏

区域里的工具栏（视频的播放、选项按钮，右边的可视化工具栏和子工具栏，音频工具栏）用 `KeyToolBar`（`src/toolbar_keys.{h,cpp}`），键盘可以进去：

- Tab 停一次，落在上次停的按钮上；第一次进入时落在一组里选中的那个（正在用的可视化工具），没有就落在第一个。点击仍然不让工具栏拿走键盘。
- 沿着工具栏的方向键在按钮之间移动（横的用 ←/→，竖的用 ↑/↓），到头不转回去；Home / End 到第一个 / 最后一个。灰掉的按钮和分隔符跳过。
- 空格或 Enter 按下，和点击一样：复选按钮翻转，单选按钮选中。用键盘按下后键盘留在工具栏上（点击可视化工具后键盘交给画面，见下面）。
- Alt+↓ 或 F4 打开按钮的菜单：带下拉菜单的按钮，以及绘图工具按钮的形状菜单（鼠标是长按）。
- 另一个方向的方向键和别的键交给区域：在视频的播放按钮上按 ↑/↓ 仍然换行，按 R 仍然播放当前行。
- 键盘所在的按钮外面画一圈强调色的圆角框：Windows 上在工具栏自己画完（`WM_PAINT`）之后补画在要重画的区域里，GTK 上接在工具栏的 `draw` 信号之后用 cairo 画。

主窗口顶上的工具栏不在任何区域里，Tab 不停（`KeyToolBar` 的 `keyboard` 参数为假），和以前一样。

## 可视化工具微调

Ctrl+Shift+方向键挪 1 个脚本像素，Alt+Shift+方向键挪 10 个（`VisualToolBase::Nudge`）。←/→ 本身已经是逐帧，所以要加修饰键。

- 拖动、缩放、旋转、矩形裁剪、矢量裁剪这些工具：挪选中的点（点击选中，Ctrl 点击多选），比如拖动工具的 `\pos`、矩形裁剪的角、矢量裁剪的节点。没有选中而工具只有一个点时（旋转的原点、横幅的终点）挪这个点；有好几个点又没选中时不动。
- 十字工具：挪所选各行的 `\pos`（以及 `\move`、`\org`），和双击定位的挪法一样。
- 正在拖动时不挪；键盘区域不在视频上时这几个键不起作用（它们是视频区域的快捷键）。
- 一秒之内连续按的算一步撤销；中间拖了一下、换了工具或改了别的东西，就从新的一步开始（`AssFile::Commit` 的 `amend_id` 只合并到紧挨着的上一步）。

## 焦点所在区域的标记

用键盘（F6、Tab）移动后，键盘所在的区域外面画一圈强调色的细线（2 DIP、圆角），画在区域之间的空隙里，不压住内容。侧边栏左边的窄条也画它经过的那一段；音频区下边那条拖动改高度的窄条就是它和编辑框之间的空隙，音频区的细线框住窄条上面的部分，底边由音频区自己画在窄条里。细线是抗锯齿的实心圆环，不是画笔描的边：Windows 上宽于一像素的画笔会把转角画成锯齿。用鼠标点一下任何地方，细线就消失，直到下一次用键盘移动：用鼠标时不需要它。

## 点工具栏不丢焦点

点击工具栏的按钮不让它拿走键盘（用键盘按下的不算：键盘留在工具栏上）。点完以后：

- 视频右侧的可视化工具栏和它的子工具栏：键盘交给视频画面，Esc、方向键、滚轮马上可用（`regions::FocusAfterClicks`）；
- 其他工具栏：键盘留在原来的地方；如果点完后哪里都没有焦点，回到字幕文本框。
