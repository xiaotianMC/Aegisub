# 主窗口的键盘区域

主窗口分成几个区域，键盘在区域之间、区域之内的走法统一（`src/keyboard_regions.{h,cpp}`）。

## 区域

按 F6 的顺序：

1. 字幕表格
2. 编辑框（样式、说话人、特效、时间、字幕文本、按钮）
3. 音频（波形）
4. 视频（画面、进度条、下方按钮）
5. 侧边栏：样式面板，文案面板显示时换成文案面板

没打开的区域跳过：没加载音频就跳过音频，没加载视频就跳过视频。侧边栏收起或隐藏时，轮到它就展开。

## 按键

- **F6 / Shift+F6**：到下一个 / 上一个区域，最后一个之后回到第一个。命令是 `app/region/next`、`app/region/previous`，可以在首选项的快捷键页里改。进入区域时键盘落在：
  - 字幕表格：表格本身；
  - 编辑框：字幕文本框；
  - 音频：波形；
  - 视频：画面；
  - 样式面板：页的切换条；
  - 文案面板：文本框。
- **Tab / Shift+Tab**：只在当前区域里转，到最后一个控件后回到第一个，不会跑进别的区域。工具栏和滚动条不停：它们的按钮没有键盘操作。侧边栏按它自己的顺序转（见 [样式面板](style-panel.md)）。字幕表格、波形、视频画面和进度条自己接收所有按键，没被快捷键用掉的 Tab 也按这条规则走。
- **Esc**：回到字幕文本框，任何区域都一样（视频的拖动预览模式下先退出拖动模式）。

以前 F6 只进出侧边栏（`app/style_panel/keyboard`）。升级时，用户快捷键里这个命令的 F6 被拿掉，F6 / Shift+F6 改给区域轮换（迁移名 `F6 regions`）；如果这两个键已被别的命令占用，就不绑定。`app/style_panel/keyboard` 命令仍在，没有默认快捷键。

## 区域里的按键

各区域原有的快捷键都不变，下面是在区域里新增的。它们都是普通快捷键，可以在首选项的快捷键页里改；已有用户升级时自动补上，某个键在它的区域里已被占用就不绑定（迁移名 `keys in regions`）。

### 字幕表格

表格里有一个“键盘光标行”，和当前行（编辑框显示的那一行）分开。原来 Ctrl+↑/↓ 只移动当前行、不改选择，但编辑框的修改作用于选中的行，移过去以后编辑框显示的那一行其实不会被修改，容易改错；现在 Ctrl 加方向键移动的是光标行，当前行和选择都不动。

- 光标行外面画一圈强调色细框，只在表格拿着键盘时画。平时它就是当前行。
- **Ctrl+↑/↓、Ctrl+PageUp/PageDown、Ctrl+Home/End**：只移动光标行。
- **Ctrl+空格**（`grid/select/toggle`）：把光标行加进选择并设为当前行；已在选择里就移出（绑定的行组整组移出）。移出的是当前行时，当前行换到离它最近的另一条选中行。最后一条选中行不能移出。光标留在原行。
- **Shift+空格**（`grid/select/range`）：选中从扩选起点（上次不按 Ctrl 移到或点到的行）到光标行的一段，代替原来的选择，光标行成为当前行。
- **Ctrl+Shift+空格**（`grid/select/range/add`）：把这一段加进原来的选择。
- 不按 Ctrl 的 ↑/↓ 等从光标行出发移动，选中新的一行；点击也把光标行放到点的那一行。
- Ctrl+空格原来是窗口的“聚焦进度条”（`video/focus_seek`），只在表格里被这条覆盖，别的地方不变。空格在表格里仍然播放视频。

### 视频（画面、进度条）

原有的 ←/→ 逐帧、Shift 跳关键帧、Ctrl 跳到行边界、Alt 大步跳、空格播放、字母键切换工具都不变。新增：

- **↑/↓**（`video/line/prev`、`video/line/next`）：上一行 / 下一行字幕，视频跳到那一行开头。
- **Home / End**（`video/jump/start`、`video/jump/end`）：跳到当前行的开头 / 结尾。原来在进度条上它们转给表格，跳到第一行 / 最后一行。

### 音频（波形）

原有的 ←/→（Z / X）上一个 / 下一个时间单位、字母键播放、Enter / G 确认、C / V 加缓冲都不变。新增：

- **Shift+←/→**（`time/start/decrease`、`time/start/increase`）：开始时间提前 / 推后 10 毫秒。
- **Ctrl+←/→**（`time/length/decrease`、`time/length/increase`）：结束时间提前 / 推后 10 毫秒（和小键盘的 − / + 相同）。
- **↑/↓**（`grid/line/prev`、`grid/line/next`）：上一行 / 下一行。
- **空格**（`audio/play/toggle`）：播放 / 停止音频选区。键盘在波形上时空格不再播放视频，其他区域照旧。

## 焦点所在区域的标记

用键盘（F6、Tab）移动后，键盘所在的区域外面画一圈强调色的细线（2 DIP、圆角），画在区域之间的空隙里，不压住内容。侧边栏左边的窄条也画它经过的那一段；音频区下边那条拖动改高度的窄条就是它和编辑框之间的空隙，音频区的细线框住窄条上面的部分，底边由音频区自己画在窄条里。细线是抗锯齿的实心圆环，不是画笔描的边：Windows 上宽于一像素的画笔会把转角画成锯齿。用鼠标点一下任何地方，细线就消失，直到下一次用键盘移动：用鼠标时不需要它。

## 点工具栏不丢焦点

工具栏的按钮不接收键盘焦点。点完以后：

- 视频右侧的可视化工具栏和它的子工具栏：键盘交给视频画面，Esc、方向键、滚轮马上可用（`regions::FocusAfterClicks`）；
- 其他工具栏：键盘留在原来的地方；如果点完后哪里都没有焦点，回到字幕文本框。

## 测试

- `selection_ui.ctrl_moves_the_keyboards_row_and_space_picks_rows_here_and_there`：Ctrl 加方向键只移动光标行；Ctrl+空格经表格自己的快捷键加入、移出（当前行换到最近的选中行、光标不动、最后一行不能移出）；普通方向键从光标行出发；Shift+空格、Ctrl+Shift+空格按扩选起点选一段；点击把光标放到点的行。
- `ordinary_edit.video_and_audio_have_arrow_keys_and_space_of_their_own`：各区域的按键找到的命令（表格的 Ctrl+空格覆盖窗口的、其他地方不变；视频的 ↑/↓、Home/End；音频的 Shift / Ctrl 加左右、↑/↓、空格；原有的左右键不变）；视频的 ↑/↓ 换行并把视频跳到行开头。
- `ordinary_edit.keyboard_regions_go_round_with_f6_and_keep_tab_inside`：区域判定；Tab 停靠点（工具栏不停、隐藏的不算）和在区域内循环；F6 前后轮换、跳过隐藏区域、命令可用；细线画在区域外的空隙里、不压内容；Tab / Shift+Tab 在接收所有按键的窗口里同样只在区域内转；点击隐藏细线；工具栏点击后焦点留在原处或交给指定窗口。
- `ordinary_edit.region_line_runs_through_the_strip_under_a_block_resized_from_below`：下边带拖动窄条的区域（音频），细线底边画在窄条里，不落到下一个区域上。
