# 字幕表格的标签图标

字幕表格的文本列有三种显示标签的方式（“视图”菜单的“显示标签 / 简化标签 / 隐藏标签”，或命令 `grid/tag/cycle_hiding` 轮换，选项 `Subtitle/Grid/Hide Overrides`，默认是简化）。原来“简化”把每个 `{…}` 都换成同一个符号 ☀，看不出是什么标签。现在每个 `{…}` 画成一个小图标块，块里的每个图标代表一类标签。

```
{\fad(200,200)\pos(640,80)}你好{\c&H0000FF&}世界{译注：双关}
→ [◐ ⌖]你好 [■]世界 [💬]
```

“显示标签”和“隐藏标签”不变。首选项里原来的“隐藏标签符号”（`Subtitle/Grid/Hide Overrides Char`）去掉了。

## 图标块

- 一个 `{…}` 一个块：浅底圆角，边框和底色按行的底色和文字颜色调出来，选中行、注释行、深色外观下都跟着变。图标高度约为字高的五分之四，块和两边的文字之间留出一个小空隙。
- 块里一类标签一个图标，按块里第一次出现的顺序排列。同一类的多个标签合成一个图标，比如 `\fscx120\fscy80` 是一个缩放、`\be1\blur3` 是一个模糊。最多画 3 个图标，多出来的写成 `+N`。
- `\t(…)` 括号里的标签算 `\t` 的，不单独画。
- **关闭的样式**：`\b0` `\i0` `\u0` `\s0` 的图标变淡。
- **颜色**直接画出标签设的颜色，四种颜色的形状不同：`\c` / `\1c` 是实心方块，`\2c` 是带一道斜线的方块，`\3c` 是色环，`\4c` 是错开的阴影方块。每个色块外面都有一圈淡淡的文字色细边，所以和底色相近的颜色（深色外观下的黑色边框色等）也看得见。
- **对齐** `\an` 画成 3×3 的点阵，标签指定的那一格是实心方块；`\a`（SSA 的写法）换算成对应的 `\an`。
- **卡拉OK**：只有 `\k` `\kf` `\ko` `\K` 的块不画成块，只画一道细竖线，把音节隔开。和其他标签写在一起时照常画成块，里面有卡拉OK图标。
- **绘图**：`\p1` 之后到 `\p0` 之前的绘图命令不当成文字显示，而是浅色的“（N 个点）”。只有 `\p0` 的块不显示。
- **备注**：没有 `\` 的 `{…}` 是备注，画对话气泡图标。
- **认不出的标签**画 `{ }` 图标，同一块里的几个合成一个。
- 文字的前 512 个字符照常显示，后面省略（和原来一样）。

## 悬停说明

鼠标停在一个图标块上，提示框逐行列出块里每一类标签设了什么，最后一行是这个块的原文（超过 300 个字符时截断）：

```
淡入淡出：淡入 200 ms，淡出 200 ms
位置：(640, 80)
{\fad(200,200)\pos(640,80)}
```

- 颜色写成 `#RRGGBB`，对齐写成 `\an` 的编号，粗体等写“开 / 关”（`\b700` 这类粗细写数值）。
- 有括号的参数在逗号后加空格；同一类有几个标签时列出原文。
- 备注只显示“备注：”和备注内容。
- 鼠标停在文字或块之间的空隙上没有提示；行号格照旧提示“点击隐藏 / 显示这一行”。

`tag_*` 是新画的，和其他单色图标一样写在 `tools/icons/generate.py` 的 `CUSTOM` 里（见 [图标与工具栏](icons.md)）。

## 实现

- `src/tag_summary.{h,cpp}`：把一行文字拆成文字段和标签块，并给出每个块里各类标签的信息（`Summarize`），以及图标名称、名称、悬停说明和纯文本形式（`IconName`、`KindName`、`Describe`、`PlainText`）。纯函数，不依赖界面。标签名按渲染器的方式取最长的匹配（`\bord` 不是 `\b`，`\fscx` 不是 `\fs`）。
- `src/grid_column.cpp` 的文本列：简化模式下 `Paint` 画文字和图标块，`Tooltip` 按同样的排版找出鼠标下的块。拆分的结果按文字缓存（最多 4000 行，超过就清空），图标按名称、尺寸、是否变淡和深浅外观缓存。`Value` 返回纯文本形式，比如 `[淡入淡出·位置]你好`。
- `src/base_grid.cpp`：鼠标移动时，把鼠标所在格子的横坐标交给那一列的 `Tooltip`（`GridColumn::Tooltip`，默认没有提示）。

## 测试

- `tag_summary.says_what_each_block_of_tags_does`：
  - 块的拆分、各类标签和顺序、颜色的 BGR 换算、悬停说明的内容和最后一行原文；
  - 取最长标签名、同类合并（`\fscx` + `\fscy`）、`\t` 里的标签不单独算、`\i0` 变淡；
  - 四种颜色分开；矩形裁剪和矢量裁剪；`\a` 换算成 `\an`；认不出的标签合成一个；
  - 只有 `\k` 的块是竖线；绘图命令数成点、结束绘图的块不显示；没闭合的 `{` 当文字；
  - 每类标签的图标都存在。
- `ordinary_edit.grid_text_column_draws_tag_chips_with_tooltips`：
  - 简化模式下画出了图标块；
  - 块上有悬停说明，块之间的文字上没有；
  - 显示标签、隐藏标签两种模式下都没有悬停说明。

浅色、深色下的绘制结果用离屏渲染看过，临时测试没有保留。
