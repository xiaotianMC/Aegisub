# ASS 补全

在字幕文本编辑框内输入 `\` 会按光标所在位置显示候选。在 `{}` 内补全 ASS 标签，在普通正文中补全 `\N`、`\n`、`\h`。

- 输入标签前缀可筛选候选，如 `\bo` → `\bord`。
- ↑ / ↓ 选择，Tab 或 Enter 接受，Esc 关闭。
- 补全列表打开时，Enter 只接受补全，不切换字幕。列表关闭后恢复原有行为。
- Ctrl+J 手动唤出；可在快捷键设置的“字幕编辑框”中修改 `edit/complete`。
- 设置 → 界面 → 字幕编辑框中的“启用 ASS 自动补全”控制自动弹出，默认开启。关闭后仍可用快捷键手动唤出。
- 对 `\pos` 等标签，补全会插入括号并将光标放在括号内；已有参数会保留。参数说明仅显示在提示中，不写入字幕文本。
- 中文输入法组词期间暂停补全。模板行的 `!…!` 表达式不提供 ASS 补全。
- `\r` 使用当前文件的样式名，`\fn` 使用缓存的系统字体名；支持中文和带空格的名称。
- `\an`、`\q`、`\i` 等提供带用途说明的参数值；颜色与透明度分别使用 `&HBBGGRR&`、`&HAA&` 格式。
- `\t(...)` 内仅提供可渐变的标签，裁剪仅提示矩形形式。

补全设置使用 Aegisub 原有配置文件保存。该项目是桌面应用，没有需要单独实现的移动端配置。
