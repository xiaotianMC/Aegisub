# C2-C 双栏差异编辑器

**文件 → 与字幕文件比较…**（命令 `subtitle/compare`）打开一个双栏差异编辑器，交互以 VS Code 的 Diff Editor 为参考，行号和行级差异提示采用 Meld 式的中间栏。它取代 C2-B 的差异列表窗口；读取流程、比较会话和 C2-A Apply Engine 不变。没有修改 `signal.h`、Undo/Redo 历史格式、保存格式或 Lua API。

## 1. 流程

1. **试探、选择文件、读取、比较**：与 C2-B 相同（编辑工具打开时先提示；编码、TXT 导入、MicroDVD 帧率等已有对话框照常弹出；`BeginComparison` 取得比较会话）。没有可应用的差异时提示并结束。
2. **窗口**（模态，标题“Compare Subtitles”）。比较会话冻结当前字幕：浏览、决定、撤销决定都只改窗口内的状态，不写入字幕。
3. **写入工程**：把会改变当前字幕的决定交给 `ApplyComparison`，作为一次 “apply comparison” 撤销步骤发布，然后结束比较，门禁释放，可以正常保存。没有这类决定时按钮显示“完成”，结束比较不改动字幕。
4. **取消**或关闭窗口：有会修改字幕的决定时先确认，然后结束比较，什么都不改。

## 2. 界面

| 区域 | 内容 |
|---|---|
| 工具栏 | 上一处 / 下一处（Shift+F7 / F7，Alt+↑ / Alt+↓，循环），“第 N / M 处差异”；应用更改 / 放弃更改（作用于当前差异）；仅显示差异 / 显示全部；同步滚动；交换左右；撤销 / 重做（Ctrl+Z / Ctrl+Y、Ctrl+Shift+Z） |
| 筛选栏 | “显示：”全部 / 仅时间 / 仅文本 / 仅样式/说话人 / 仅其他字段 / 多项 / 新增 / 删除，各带数量，一次选一类（数量为 0 的类别不显示）；“忽略：”时间 / 文本 / 样式和说话人 / 其他字段（见 §3 筛选） |
| 标题 | 左“基准版本：文件名”，右“当前版本：文件名”；当前打开的字幕所在一侧标“目标工程”并用强调色 |
| 左右两栏 | 每个比较项目一行，两侧对齐：开始、结束、样式、说话人（有说话人时才显示）、文本；层、边距、特效、注释、附加数据有变化时收成文本后的一个灰色标签：只变一项时显示“字段: 值”，多项时显示“+N 项”。左栏的垂直滚动条在外侧，行一直延伸到中间栏 |
| 中间栏 | 左右两侧的行号各贴近自己的一栏；每处差异一条色带连接两侧（两栏不同步滚动时色带弯曲，连到各自的位置）；`»` 采用左侧（放弃更改），`«` 保留右侧（应用更改），已选的箭头实心显示，再点一次重置为待处理；`⇅` 顺序变化、`?` 时间与文本指向不同行或多个相同候选，标在色带中间。滚轮同时滚动两栏 |
| 右栏附加 | 勾选框：只在已勾选、鼠标所在或当前的行显示，有任何一处勾选后全部显示（多选状态）。操作列：鼠标所在行和当前行显示“✓ 应用 / ✕ 放弃”按钮（已处理时为“已接受 / 已拒绝 / 部分接受”和 ↺ 重置），其他行只显示状态图标（○ 待处理、✓、✕、◐）。最右侧概览条标出全部差异和当前视口，可点击或拖动跳转 |
| 明细行 | 当前差异是变了两项及以上的修改行时，在它下方每个变化字段占一行：左右各显示字段名和该侧的完整值（文本带逐字高亮），中间栏的 `»` / `«` 只决定这一个字段，右栏显示该字段的状态（左侧 / 右侧 / 待处理）。切换当前差异时明细行随之移动，被点击的行保持在原位置 |
| 批量 | 全选差异、已勾选数量、应用所选 / 放弃所选；统计“待处理 · 已接受 · 已拒绝 · 部分接受”；应用全部更改 / 放弃全部更改 |
| 报告 | 每次决定后试运行（`CheckApply`）：将修改、新增、删除的行数，要复制的样式和附加数据；不能写入时列出原因，“写入工程”禁用 |

### 视觉

- 行级（与中间栏色带同色，整行着色）：修改两侧均为蓝色底；新增右侧绿色底，删除左侧红色底，空的一侧为同色调的浅色斜纹占位。同类相邻的差异连成一块，块的上下边缘画线并经中间栏连到另一侧。
- 行内：只有文本使用填色高亮。时间、样式、说话人变化时文字加粗并加一条细下划线（左红右绿）。右侧变化的时间后用小字显示变化量（`+600ms`、`+1.5s`、`−0:02.0`），小于 100 毫秒的显示得更淡。文本按词元标出变化的部分（覆盖标签块、`\N` 等转义、英文单词、空白各为一个词元，其余每个字符一个词元，中文因此按字比较）。
- 已处理的行颜色变浅；被舍弃的一侧（整行，或修改行中被舍弃的字段）变灰并加删除线。
- 当前差异：行底加深，两栏和中间栏都用强调色边框（连同它的明细行）。中间栏的 `»` / `«` 只在鼠标所在行和当前行显示。悬停一行显示完整内容、变化字段、状态和匹配说明。
- 悬停在按钮上（✓ 应用、✕ 放弃、↺ 重置、勾选框、中间栏 `»` / `«`、折叠条、概览条）时，工具提示和面板下方的说明行都显示该按钮的作用；移开后说明行恢复默认提示。
- 颜色有浅色、深色两套，随系统外观（`wxSystemSettings::GetAppearance().IsDark()`）选择。

### 折叠

“仅显示差异”（默认）：连续不显示为差异的行（相同的行，以及被筛选掉的差异）只保留每处差异前后 3 行，其余折叠为“N 个隐藏的行 · 点击展开”，两栏同时显示；点击后在原位展开。只隐藏 1 行时不折叠。“显示全部”不折叠；切回“仅显示差异”时重新折叠。

### 滚动与定位

两栏各有滚动条，默认同步（垂直和水平）。关闭同步后各自滚动；点击一行时，如果另一栏看不到对应行，就把它滚到与点击一栏相同的位置。导航到某处差异时两栏都滚动到可见。滚轮滚动，Shift+滚轮水平滚动；栏获得焦点后方向键、PageUp/PageDown、Home/End 滚动，空格勾选当前差异。

## 3. 语义

左侧为基准（Original），右侧为当前（Modified）。默认当前打开的字幕（目标工程）在右侧，比较的文件在左侧；“交换左右”把目标工程换到左侧，用于“把对方修订过的文件合入我的工程”这类场景。

| 操作 | 含义 | 目标工程在右侧 | 目标工程在左侧 |
|---|---|---|---|
| 应用更改 | 保留右侧内容 | 工程不变 | 取文件中的内容 |
| 放弃更改 | 恢复左侧内容 | 取文件中的内容 | 工程不变 |
| 待处理 | 未决定 | 工程不变 | 工程不变 |

决定按“对工程的效果”保存（哪些字段取文件中的值），所以交换左右后已接受的变为已拒绝、反之亦然，写入结果不变。新增、删除的行整行处理；修改行可逐字段处理（明细行的 `»` / `«`，或右键菜单“保留右侧：字段”），在待处理的行上选一个字段时，其余字段保持工程原样，状态为“部分接受”。

### 筛选

- **类别**按修改行中（未被忽略的）变化字段所属的组划分：时间（开始、结束）、文本、样式和说话人、其他字段（层、边距、特效、注释、附加数据）。只涉及一组的归入对应的“仅……”类，涉及多组的为“多项”；新增、删除各成一类。
- 选择一类后只显示该类：导航、计数（“第 N / M 处差异（共 T 处）”）、全选、“应用全部更改 / 放弃全部更改”都只作用于显示的差异；其余差异按未变化的行折叠，保持原来的决定。确认框写明“当前显示的 N 处差异”。
- **忽略**某组字段后，这些字段不高亮、不出现在明细行、不计入类别；只变了被忽略字段的行不再算作差异。此时的应用 / 放弃（单项、批量、右键菜单）只改动未忽略的字段，被忽略字段保持原来的选择（未决定时保持工程原样），确认框会列出被忽略的字段。重置为待处理始终重置整行。
- 筛选只影响显示和决定的范围，不改变比较结果，也不改变已经做出的决定。所选类别没有差异时自动回到“全部”。

撤销 / 重做只针对窗口里的决定：单项、批量、逐字段各为一步，新的决定清除重做记录。勾选不进入撤销记录。

批量操作先确认：说明范围（全部 N 处 / 当前显示的 N 处 / 所选 N 处）、其中会改变的数量、会被覆盖的相反决定数量，并说明可以撤销、写入前不修改字幕。没有会改变的项目时只提示。

## 6. 未处理与风险

- 自绘栏没有无障碍接口（屏幕阅读器读不到行内容）。工具栏、筛选栏和批量按钮是标准控件，可用键盘操作；逐字段选择现在只能通过明细行的箭头或右键菜单完成，原来的字段条（标准勾选框）已去掉，所以单靠键盘无法逐字段决定。
- 行高固定，长文本不换行，靠水平滚动和悬停提示查看全文。
- 新增和删除各占一行，不像 VS Code 那样把相邻的删除与新增并排放在同一行（字幕行是离散条目，这样每行的按钮只对应一个条目）。
- 比较仍在宿主线程同步运行；字段宽度用字符数估算，不逐行测量。
- Windows/MSVC 未构建；GTK 下的真实鼠标交互（点击、拖动概览条、右键菜单、中间栏箭头）未做手动验证，测试通过发送 wx 事件驱动，外观只检查了浅色主题。
