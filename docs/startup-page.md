# 启动页与项目看板

直接启动 `Aegisub-Native.exe` 时，先进入浅色的 Windows 风格启动页。

- 左侧“项目看板”：进入独立的项目页面，目前显示项目空状态。可返回启动页，也可打开字幕编辑器。
- 右侧“字幕编辑器”：直接进入原有字幕编辑环境。
- 从 Windows 双击字幕文件，或启动时传入文件路径，仍直接进入编辑器并打开文件。
- 启动页使用自绘的浅色标题栏、圆角卡片、蓝色强调色和悬停 / 键盘焦点反馈；支持最小化、最大化、还原、关闭及拖动窗口。系统支持时使用 Windows 11 窗口圆角。
- Tab 切换按钮焦点，Enter / Space 激活按钮；项目看板中按 Esc 返回启动页。

本阶段按约定只提供启动页及看板页面，不加入项目创建、打开或保存。没有新增项目存储，原有字幕保存与配置机制继续沿用。

## 界面检查

1. 无参数启动：确认只显示启动页，没有提前弹出编辑器。
2. 点击左侧功能块：确认进入项目看板，返回按钮和 Esc 均可回到启动页。
3. 点击右侧功能块：确认打开原编辑器并关闭启动页；看板中的编辑器入口效果相同。
4. 使用键盘 Tab、Enter / Space 操作按钮，检查悬停、焦点及缩放后的卡片显示。
5. 检查标题栏拖动、最小化、最大化 / 还原及关闭行为。
6. 带字幕文件路径启动：确认绕过启动页并载入该文件。
