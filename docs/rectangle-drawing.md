# 原生矩形绘图（Aegisub 3.5.1 增强版）

运行便携目录中的 `Aegisub-Native.exe`。

## 使用

1. 打开视频，或通过“视频 → 使用虚拟视频”准备预览画面。
2. 选中一条在当前画面可见的字幕。
3. 选择“视频 → 绘制矩形”，也可以点击视频左侧工具栏的蓝色实心矩形图标（位于矩形裁剪图标上方）。
4. 在画面内按住鼠标左键拖出矩形，松开后新增一条绘图字幕。支持任意拖拽方向；单击不会创建零面积图形，拖动期间可按 Esc 取消。
5. 新增行自动选中。用原有的颜色按钮调整填充色及透明度，用移动、缩放工具调整位置和大小。
6. 按 Ctrl+S 保存字幕；Ctrl+Z 可撤销一次矩形创建。

默认矩形为 75% 不透明的黑色，无描边和阴影。矩形使用当前字幕行的时间、样式和层级，并插在原行之前，使它显示在原字幕下方。原行的文字、标签和时间不被改写。多行被选中时，以当前活动行为参照创建一个矩形。

矩形模式用于创建新图形，再次拖拽会再新增一个矩形；已有矩形的移动、缩放继续使用原有工具。

## 保存与平台

矩形是标准 ASS `\p1` 矢量绘图，直接写入字幕文本，随 `.ass` 文件保存，无需额外插件或配置文件。已在 Windows 桌面版中验证保存、重新打开、原文保护和撤销。此编辑工具没有移动端版本；播放端需支持 ASS 矢量绘图。

此增强版同时包含原生样式列表按长名称加宽及悬停显示完整名称的改动。原有安装保持独立。

## 开发验证

- Aegisub 自带测试：2/2 通过。
- 实际界面验证：正常和反向拖拽、单击不创建图形、单步撤销、保存后重新载入。
- 保存结果检查：`python tests/data/check_saved_rectangle.py <另存的测试ASS>`，输入应由 `tests/data/rectangle-test.ass` 在实际界面绘制一个矩形后另存得到。
- 空间上限：坐标限制在视频画面内，宽高至少为一个脚本像素。
