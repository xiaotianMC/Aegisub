# 原生形状绘图（Aegisub 3.5.1 增强版）

运行便携目录中的 `Aegisub-Native.exe`。

## 使用

1. 打开视频，或通过“视频 → 使用虚拟视频”准备预览画面。
2. 选中一条在当前画面可见的字幕。
3. 选择“视频 → 绘制矩形”，也可以点击视频左侧工具栏的蓝色形状图标（位于矩形裁剪图标上方）。长按左键约 0.4 秒，向右展开形状菜单，点击切换矩形、椭圆 / 圆形、三角形、任意多边形。右键点击工具按钮也可打开此菜单，按钮图标随选择改变。
4. 矩形、椭圆、三角形：按住鼠标左键拖拽，松开后新增一条绘图字幕。支持任意拖拽方向；按住 Shift 约束为正方形、正圆或等边三角形。单击不会创建零面积图形，拖动期间可按 Esc 取消。
5. 新增行自动选中。用原有的颜色按钮调整填充色及透明度，用移动、缩放工具调整位置和大小。
6. 多边形：单击依次添加顶点，双击、Enter 或点击起点闭合并完成。Shift 将下一条边约束为水平、垂直或 45° 方向；Backspace 移除上一顶点，Esc 取消。凹多边形也可绘制，少于三个顶点或所有顶点共线时不创建图形。
7. 按 Ctrl+S 保存字幕；Ctrl+Z 可撤销一次图形创建。

默认图形为 75% 不透明的黑色，无描边和阴影。图形使用当前字幕行的时间和层级，自动采用专用“图形”样式（不存在时创建），并插在原行之前，使它显示在原字幕下方。原行的文字、标签和时间不被改写。多行被选中时，以当前活动行为参照创建一个图形。

绘图模式用于创建新图形，完成后可继续绘制同类图形。切换字幕、视频帧或绘图工具会取消未完成的图形。

## 图形属性编辑

在字幕列表中右键点击图形所在行，选择“编辑图形…”，也可以选中图形字幕后按 Enter（含小键盘 Enter），或直接左键双击该行。面板可设置宽度、高度、位置 X / Y、填充颜色和透明度。点击颜色块使用原生颜色选择器。透明度 0% 为不透明、100% 为完全透明。

支持矩形、椭圆、三角形、任意多边形、贝塞尔曲线、B 样条和同一路径中的多个子图形，包括负坐标及不同的 `\p` 绘图等级。宽高使用旋转前的绘图控制点边界，以脚本像素计；修改尺寸通过 `\fscx` / `\fscy` 实现，保留原始路径及曲线控制点，不会把其他形状改成矩形。位置 X / Y 是 ASS 对齐锚点，非左上对齐的图形不把它作为左上角。

编辑期间，有效的尺寸、位置、颜色和透明度立即同步到原生字幕文本框、字幕列表和视频预览。未完成或越界的数字不会写回。取消会恢复打开弹窗前的原文；改回原值后确认不产生修改，确认后的整次编辑可一次撤销。时间、样式、层级、旋转和未修改的其他标签保持原样。普通文本行右键菜单不显示此入口，双击文字行仍保留原有跳转行为。混合文字与绘图、多个独立绘图块或带运动 / 变换 / 样式重置的复杂行不进入此静态属性面板，避免改坏复杂特效。

## 放大后拖动预览

默认不再因为画面被放大而自动切换成小手。需要使用视频左侧工具栏的“拖动预览”按钮进入拖动模式：按钮按下后光标变为小手，按住左键即可拖动画布查看被裁掉的部分，拖动只改变预览位置，不修改字幕或图形坐标。再次点击该按钮退出拖动模式，画面恢复完整显示的原大小。拖动模式开启时，绘图、移动、裁剪等工具的左键操作暂停；按住中键仍可在任意工具下临时平移。切换到其他工具也会退出拖动模式并恢复原大小。

## 保存与平台

所有形状都是标准 ASS `\p1` 矢量绘图，椭圆使用四段三次贝塞尔曲线，直接写入字幕文本，随 `.ass` 文件保存，无需额外插件或配置文件。已有矩形保存、重新打开、原文保护和撤销流程已在 Windows 桌面版中验证，其他形状复用此流程。此编辑工具没有移动端版本；播放端需支持 ASS 矢量绘图。

此增强版同时包含原生样式列表按长名称加宽及悬停显示完整名称的改动。原有安装保持独立。

## 开发验证

- Windows 原生控件回归：在完成编译的 Visual Studio 开发者终端运行 `python tests/run_native_preview_regression.py build`，检查弹窗打开期间的实时同步、原值恢复、取消、无效输入、单步撤销，以及侧边栏拖动模式（开启、裁切画面拖动、松键 / 失去捕获、退出恢复原大小、切换工具退出）和任意工具下的中键平移。测试使用独立配置和自有窗口，不注入系统鼠标或键盘输入。
- Aegisub 自带测试：2/2 通过，包含 385 项 C++ 测试；形状路径、退化图形、通用绘图边界解析和四个方向的 Shift 比例及边界约束均有测试覆盖。
- 实际界面验证：形状菜单切换、椭圆、反向拖拽三角形、凹多边形预览、Enter 完成及 Backspace 撤回顶点。长按和 Shift 组合鼠标手势仍需人工复核。
- 通用属性面板界面验证：文本行隐藏入口、双击椭圆打开、Enter 打开、负坐标复合曲线和 `\p2` 默认锚点读取、原值确认与取消。椭圆从 120×60 调整到 180×60 后保存，确认原始曲线路径、元数据和其余七行均未改动。
- 此前矩形界面验证：正常和反向拖拽、单击不创建图形、单步撤销、保存后重新载入。
- 保存结果检查：`python tests/data/check_saved_rectangle.py <另存的测试ASS>`，输入应由 `tests/data/rectangle-test.ass` 在实际界面绘制一个矩形后另存得到。
- 空间上限：坐标限制在视频画面内，宽高至少为一个脚本像素。
