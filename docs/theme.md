# 外观：浅色与深色

**首选项 → 界面 → 外观 → 主题**：跟随系统（默认）/ 浅色 / 深色。配置项 `App/Theme`（0 / 1 / 2）。

## 规则

- **界面颜色选项含义不变**：深色外观下，用户**没改过**的界面颜色读作它的深色默认值；改过的颜色在两种外观下都照用户的设置。判断依据是配置项是否仍为出厂值（`OptionValue::IsDefault()`），所以以后把颜色改回默认，也会自动恢复跟随外观。
- **哪些颜色跟随外观**：字幕网格的全部颜色、编辑框的背景和语法高亮、视频位置框（关键帧时借用网格选中色）、字数超限提示。
- **哪些不跟随**：音频波形和频谱（本来就是深色底）、视频画面上的可视化工具、样式编辑器的预览背景、虚拟视频的上次颜色。这些画在画面或波形上，和界面明暗无关。
- **对比页、标签条、锁定提示条**：使用主题模块提供的强调色和提示条颜色，深色下也有对应配色。

各平台如何让原生控件变深：

- **Linux（GTK3）**：深色时，若装有当前主题的 `-dark` 版本（如 `Yaru-dark`）就切换过去，否则打开 GTK 的“偏好深色”；浅色时去掉主题名的 `-dark` 后缀；跟随系统时恢复启动时的主题。只在 GTK3 构建且找到 `gtk+-3.0` 时编译（`WITH_GTK3_APPEARANCE`）。实测 Yaru 主题只开“偏好深色”时输入框仍是白色，因此优先切换到 `-dark` 主题。
- **Windows**：内置 wxWidgets 已升级到 3.3.4（见 [升级到 wxWidgets 3.3](wx33.md)），启动时调用 `MSWEnableDarkMode`，原生控件一起变深；凹陷 / 凸起边框改为平边框，启动页也跟随外观。若自行用 wx 3.2 构建，Windows 原生控件不能变深，“跟随系统”按浅色处理，手动选“深色”时只有自绘部分变深。
- **macOS**：跟随系统外观；手动选浅色或深色只影响自绘部分（未实现强制系统外观）。

## 切换时机

- 自绘部分（网格、编辑框、对比页、标签条）通过 `theme::AddChangeListener` 立即重绘。
- 原生控件：启动时就是深色可以完全变深；运行中切换时，GTK 的部分控件（输入框、下拉框）因 wx 缓存了系统颜色，要重启后才完全切换。首选项里有这条说明。

## 测试

`ordinary_edit.dark_appearance_uses_dark_defaults_only_for_unchanged_colours`：浅色 / 深色下读到对应默认值；每次修改设置都会通知；用户改过的颜色在深色下保持；恢复默认后重新跟随外观；没有深色默认值的选项（音频播放光标）照原值；标签条提示条在切换后立即换色。

离屏截图检查过：浅色主界面、运行中切到深色、启动即深色的主界面（网格、编辑框、原生控件）、深色下的对比页和锁定提示条；这个临时测试没有保留。
