# 命令面板

**Ctrl+Shift+P**，或菜单 **视图 → 命令面板**：在主窗口上方弹出一个输入框，输入后列出匹配的命令，回车执行。以 `@` 开头搜字幕对白，以 `:` 开头跳到某一行或某个时间（见下文“前缀”）。

## 使用

- 列出全部命令（菜单、工具栏、快捷键能用的命令，以及自动化脚本的宏），不含“最近打开的文件”这类条目和命令面板自己。
- 每行：图标、名称（匹配的字符加粗并用强调色）、所在菜单（名称后，灰色，如“时间轴”“视频 › 缩放”）、快捷键（右侧）、说明（第二行）。开关和单选类命令在当前为开时名称前有 ✓。
- 当前不能执行的命令（例如没有打开视频时的视频命令，或对比标签页在前时的编辑命令）显示为灰色，说明前标“当前不可用”，回车不执行。
- 什么都没输入时，最近使用过的命令排在最前（最多 12 个，存于 `App/Command Palette/Recent`），其余按名称排序。
- ↑ / ↓ 选择（到头会绕回），PageUp / PageDown 翻页，Enter 或双击执行，Esc 或点到别处关闭。命令在面板关闭之后才执行，所以执行的命令可以再打开对话框。

## 匹配

- 不区分大小写；输入的字符按顺序出现在名称里就算匹配（`os` 能找到“Open Subtitles”）。
- 输入有空格时分词：每个词各自匹配，顺序不限，可以落在不同地方（名称、菜单、英文名），`tags hide` 能找到“Hide Tags”。同时也把整句去掉空格匹配一次，取得分高的。
- 排序：单词开头的字符、连续的字符得分高，中间跳过的字符扣分；得分相同时名称短的在前；最近用过的命令额外加分。
- 中文名称可以用拼音全拼或首字母找：“打开字幕”能用 `dakaizimu`、`zimu` 或 `dkzm` 找到，高亮对应的汉字。拼音来自 ICU 的 Han-Latin 转写（项目已依赖 ICU，不另带拼音表）；多音字按 ICU 的常用读音。若系统的 ICU 缺少这项数据，只是不能用拼音。
- **英文原名**：界面是中文时，英文名（翻译前的 `STR_DISP`）也能搜，`shift times` 找到“平移时间”，英文名显示在第二行说明前并高亮。得分比名称本身略低；动态名称的命令（撤销、显示 / 隐藏工具栏等）没有固定的英文名，不参与。
- **所在菜单**：菜单栏里的位置（翻译后的子菜单名，去掉助记符）也能搜，同样支持拼音，得分低于名称：`时间 平移`、`timing shift` 都能找到“平移时间”，菜单里匹配的字也高亮。不在菜单栏里的命令没有这一项；同一命令在多处时取第一处。读的是用户的 `menu.json`（或默认菜单）。
- **快捷键**：输入像快捷键的内容时按快捷键找，写法随意：`ctrl+s`、`Ctrl-S`、`s ctrl`、`shift+ctrl+p` 都行，修饰键顺序不限。完全相同的排第一，右侧显示这个快捷键并用强调色。只有修饰键并以 `+` / `-` 结尾（`ctrl+shift+`）时，列出带这些修饰键的所有命令。单独的 `F1`–`F24` 也算；单独一个字母不算（那是在输入名称）。查的是所有快捷键上下文（Default、Always、编辑框、字幕表格、音频、视频、翻译助手）。
- 也匹配命令 ID（如 `subtitle/open`，不高亮）；以上都不匹配时，说明文字里包含输入内容（至少两个字符）的命令排在最后。
- 输入法组字（拼音还没上屏）时，Enter 和方向键交给输入法，不会误执行命令（Linux GTK；Windows 的输入法本来就不把这些键交给程序）。

## 前缀

输入的第一个字符决定搜什么；中文输入法打出的全角 `＠`、`：` 也算。底部左侧提示这两个前缀。

### `@` 搜字幕对白

- 在当前字幕的所有行里找（包括注释行），按文件顺序列出。每行：对白（去掉 `{}` 标签，`\N`、`\n`、`\h` 换成空格；命中的字加粗并用强调色）、开始时间（右侧）；第二行是行号、“注释”（如是）、样式、说话人。
- 和找命令不同，每个词必须**连续**出现，不能分散：对白比命令名长得多，分散匹配几乎什么都能命中。可以用原文、拼音全拼或首字母，拼音要从某个字的音节开头算起（`zimu`、`zm` 能找到“字幕”，`imu` 不行）。有空格时分词，每个词都要出现，顺序不限。
- 最多列 500 行，超出时最后一行提示还有多少行匹配。
- 回车：选中这一行并设为当前行，字幕表格滚到它；开了设置里的“选择的行改变后，视频位置变为所选行的开始时间”的话，视频也跟着跳。
- 只输入 `@` 时提示该输入什么。所有行在第一次用 `@` 或 `:` 时读一次，此后面板开着期间不再读（面板是模态的，字幕不会变）。一万行时第一次约 0.2 秒，之后每次输入约 30 毫秒。

### `:` 跳到行或时间

- `:120`：跳到第 120 行（和字幕表格左边的行号一致）。超出范围时提示共有多少行。
- `:1:23.45`、`:0:01:23`、`:83.5`：有 `:`、`.` 或 `,` 的当作时间（按 ASS 时间的写法解析，`1:23` 是 1 分 23 秒）。列出两行：“视频跳到 …”和那个时间屏幕上的字幕行（有几行同时显示时取开始得最晚的那行；没有就取之后第一行；注释行不算）。没有打开视频时，跳视频那一行是灰的，字幕行排在前面。
- 全角数字和 `：` 也认。

对比标签页在前时，这两种模式的行都显示但不可用，和编辑命令一样。

## 实现

| 部分 | 位置 |
|---|---|
| 匹配、拼音、快捷键、对话框 | `src/command_palette.{h,cpp}` |
| 英文原名 | `src/command/command.h` 的 `STR_DISP` 宏同时生成 `StrDisplayOriginal()` |
| 菜单路径 | `menu::CommandPaths()`（`src/menu.cpp`） |
| 命令 `app/command_palette` | `src/command/app.cpp` |
| 快捷键 | `src/libresrc/default_hotkey.json`（及 macOS 版）；已有用户配置通过 `src/hotkey.cpp` 的迁移补上，组合键已被占用时不补 |
| 菜单 | `src/libresrc/default_menu.json`（视图菜单末尾） |
| 列表颜色 | `theme::UiColours()` 的 `list_*`，随浅色 / 深色变化 |

输入框是原生控件（输入法、复制粘贴、右键菜单照常可用）；结果列表是自绘的 `wxVListBox`。窗口是无标题栏的模态对话框，失去焦点即关闭。各命令的可用和开关状态在该行第一次显示时才读取，和菜单一样。

## 测试

- `ordinary_edit.command_palette_matches_word_starts_runs_and_pinyin`：单词开头优先、连续优先、命令 ID 可搜不高亮、拼音全拼 / 首字母 / 汉字本身的匹配与高亮位置。
- `ordinary_edit.command_palette_matches_words_in_any_order_english_names_menus_and_shortcuts`：分词乱序、每个词都要匹配；英文原名的匹配、高亮和排在名称之后；菜单与名称分别高亮；快捷键各种写法的规范化。
- `ordinary_edit.command_palette_finds_dialogue_as_runs_and_reads_goto_queries`：对白的连续匹配（原文任意位置、拼音从音节开头、首字母必须相邻、分词）；`:` 后面的行号和时间解析，包括全角。
- `ordinary_edit.command_palette_finds_lines_and_goes_to_lines_and_times`：`@` 的结果、去标签、高亮、行号 / 说话人、注释行、全角 `＠`、无结果和空输入的提示；`:` 跳行、超出范围、按时间找屏幕上的行、没有视频时不能跳视频；通过命令选中后在面板关闭后跳到那一行；对比标签页在前时不可用。
- `ordinary_edit.command_palette_lists_commands_remembers_choices_and_runs_after_closing`：列表内容与快捷键；分词搜索、菜单路径、按快捷键找（含只有修饰键的前缀）；不可用命令不执行；无结果；通过命令打开、选择、关闭后执行；最近使用排序；开关命令打勾；对比标签页在前时只有应用命令可用。

离屏截图检查过浅色和深色下的结果列表与无结果提示；这个临时测试没有保留。
