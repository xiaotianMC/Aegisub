# 滚动特效的可视化编辑

编辑框的“特效”栏（Effect 字段）里，渲染器认得三种动画：

| 写法 | 效果 |
| --- | --- |
| `Banner;延迟[;从左到右[;淡出宽度]]` | 横幅：文字从右往左（第二个数为 1 时从左往右）横穿画面 |
| `Scroll up;y1;y2;延迟[;淡出高度]` | 向上滚动：文字从区域底边升起，只在 y1 和 y2 之间显示 |
| `Scroll down;y1;y2;延迟[;淡出高度]` | 向下滚动：文字从区域顶边落下 |

**延迟**是文字移动一个脚本像素所用的毫秒数，所以速度是 1000 ÷ 延迟 像素/秒。延迟按整数计，0 当作 1。淡出宽度 / 高度只有 VSFilter 用，libass（mpv 等大多数播放器，以及本程序的预览）不理会。名称区分大小写，`scroll up;…` 不起作用。

以前只能在特效栏里手敲这些数字，看不到区域在哪、速度多快。现在可以在视频上直接拖，也可以用表单填。

## 视频上的“滚动特效”工具

视频右侧工具栏里，矩形绘图下面的上箭头图标。

- **滚动区域**：区域外压暗，上下两条边各有一个方形手柄，拖动改 y1 / y2。区域中间的箭头表示方向。
- **结束位置**：虚线标出行结束时文字前沿所在的位置。拖它的三角手柄就是在改速度：拖远走得快，拖近走得慢，延迟按“到行结束走这么远”反算并取整，手柄随即停在取整后的实际位置。
- **当前位置**：细实线标出当前帧文字前沿所在的位置，文字已滚出画面时也能看到它走到了哪。
- **横幅**：在行的高度画一条横向箭头，结束位置是一条竖虚线，同样拖动改速度。
- 左上角显示“N px/s, 行结束时移动 M px”。
- **双击**翻转方向：向上 ↔ 向下，从右往左 ↔ 从左往右。
- **新建**：特效栏为空时，在画面上按住竖向拖一下，就生成 `Scroll up;上;下;延迟`，延迟取“行结束时刚好走完区域高度”。只单击不生成。已有滚动时，拖出新区域会替换上下边，保留速度。
- 特效栏里有别的内容（卡拉 OK 模板的 `template`、`code` 等）时，工具只提示“特效栏已有其他内容”，不改它。横幅不能拖出区域。
- 选中多行时，改动作用于选中行里同一类（都是滚动，或都是横幅）的行：拖边界把那条边设成同一个值，拖结束位置把延迟设成同一个值，双击各自翻转。其他行不动。
- 拖动过程中只预览，不写入；松手后写入，一次拖动是一步撤销。Esc 取消，不留撤销记录。

## 编辑框的表单

点特效栏右边的下拉箭头，最上面是“横幅 / 滚动特效…”，下面照旧是文件里已有的特效值。

- 选类型：无 / 横幅 / 向上滚动 / 向下滚动；横幅再选方向。
- 区域的上、下边；速度（延迟），旁边实时换算成“N px/s, 行结束时移动 M px”。
- “边缘淡出（仅 VSFilter）”勾上后才写淡出值。
- 从“无”第一次切到横幅或滚动时，延迟预设为行结束时刚好横穿画面 / 走完区域。
- 原样点确定不改写特效栏；选“无”清空它。特效栏里有别的内容时，表单提示确定后会替换它，选“无”则保持不动。
- 确定后和手动输入一样作用于选中的行，是一步撤销。

## 实现

- `src/scroll_effect.{h,cpp}`：按 libass 的方式解析和生成（名称后每个 `;` 取一个整数，最多四个；横幅至少一个、滚动至少三个，否则不算），以及位移、延迟换算。
- `src/visual_tool_scroll.{h,cpp}`：视频工具。可视化工具的基类原来只写回文本，现在 `SetEffect` 也能预览并写回特效栏，特效变了提交时带 `COMMIT_DIAG_META`。
- `src/dialog_scroll_effect.{h,cpp}`：表单，从 `SubsEditBox::EditScrollEffect` 打开，结果交给特效栏原有的修改流程。

## 验证

`ordinary-edit-tests` 里：

- `scroll_effect.reads_and_writes_the_fields_as_the_renderers_do`：解析、生成、往返，非滚动内容和小写名称不识别，延迟和位移的换算。
- `visual_edit.scroll_*`：拖边界（预览不写入、一次提交、撤销）、拖结束位置改速度（滚动和横幅）、双击翻转、空特效栏拖出区域而单击不生成、别的内容和横幅不被改、Esc 取消、多选只改同类行；`all_standard_tools_reject_comparison_writes` 也覆盖这个工具。
- `ordinary_edit.scroll_effect_form_sets_the_effect_field_in_one_step`：表单设置、一步撤销、取消、原样确定不改写、选“无”清空、别的内容保留。

还需要人工核对：在带视频的工程里逐帧看文字实际位置是否和两条标记线对齐，并用 mpv 播放另存的文件。
