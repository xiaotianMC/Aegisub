# 序号栏显示 / 隐藏

在字幕列表最左侧的序号栏，单击某行的序号，即可隐藏该行；序号位置显示小眼睛加斜杠的隐藏图标。再次单击图标，恢复字幕显示和行号。悬停可查看操作提示。

每次只切换点击的那一行，不改变当前活动行和多选范围。其他列仍可正常选择和拖动；Ctrl / Shift / Alt 配合点击序号仍保留原有的选择行为。原有“注释”勾选框也能控制隐藏状态，支持 Ctrl+Z / Ctrl+Y。

隐藏复用标准 ASS 注释行：内容、时间、样式和顺序均保留，随 `.ass` 文件保存，重新打开后仍保持状态。字幕列表继续显示该行，以便恢复；视频预览和正常播放不显示它。不要导出为不支持注释行的格式来保存隐藏内容。

这是桌面版编辑入口，没有移动端应用；保存的 ASS 注释行可由其他支持 ASS 的编辑器识别。

开发检查：`python tests/data/check_line_visibility.py <原始ASS> <保存的ASS> <逐行D或C>`，例如 `DC` 表示第一行显示、第二行隐藏。该检查也验证所有事件字段保持不变。

已在 Windows 实际界面验证：单击隐藏与恢复、快速连续点击、活动行与未选中行、撤销与重做、保存后重开。保存结果检查确认各行内容、时间、样式和顺序均保留；原有测试 2/2 通过。
