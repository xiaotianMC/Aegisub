# 主界面与首选项

阶段 4 的改动：首选项搜索、字幕网格的外观、状态栏和按缩放计算的尺寸。编辑框的布局没有改（见文末）。

## 首选项搜索

首选项窗口顶部有搜索框，输入设置的名称、拼音全拼或拼音首字母（例如“音频”可以输 `yinpin` 或 `yp`），大小写和空格不计。

- 匹配的设置标签加粗并用强调色显示；左侧有匹配的页面加粗，没有匹配的页面变灰。
- 当前页没有匹配时自动切到第一个有匹配的页面；按回车或放大镜依次切到下一个有匹配的页面。
- 搜索框旁边显示找到几项、分布在几页；没有匹配时显示“没有匹配的设置”。
- 页面名称本身也参与匹配，例如搜“快捷键”会找到快捷键页（这一页的内容是列表，列表里的命令请用该页自己的搜索框）。
- 分组框标题（如“音频栏”）参与匹配，但标题本身不变色：分组框的字体和颜色会传给框里的所有控件。

实现：`src/preferences.cpp`（`Preferences::IndexPages`、`Search`），拼音和规范化沿用命令面板的 `palette::MakeKeys` / `NormaliseQuery`。

## 字幕网格

- **隔行底色**：普通行每隔一行略深一点（由“标准前景色”向背景色按 3.5%，深色下 4.5% 混合得到，所以用户自定义的网格颜色照样生效）。可在“首选项 → 界面 → 网格 → 隔行加底色”关闭（`Subtitle/Grid/Alternate Rows`）。
- **注释行变淡**：未选中的注释行文字按 55% 与行底色混合，行号列的“闭眼”图标同样变淡。选中后恢复选中文字色。
- **选中行强调色条**：选中的行在最左侧画一条 3 DIP 宽的强调色竖条（主题模块的强调色），当前行的边框照旧。
- **行高随缩放**：行高 = 字体高度 + 4 DIP。100% 缩放时与原来完全相同；缩放更大时上下留白按比例增加，图层列的绑定色块和 CPS 超限色块同样填满整行。

## 状态栏

主窗口状态栏分四栏：菜单帮助、临时消息（原有）、**当前行**、**文件状态**。

- 当前行：`第 12 行，共 340 行 · 0:01:02.34 → 0:01:05.00`；多选时加“（选中 3 行）”。没有当前行时为空。
- 文件状态：有对比打开时显示“正在与 other.ass 对比”，否则显示“未保存的更改”或“没有未保存的更改”。
- 在当前行、选择、字幕内容、保存和对比标签变化时更新。对比标签的变化通过新加的 `WorkspaceTabs::AddChangeListener` 通知。

实现：`src/status_info.{h,cpp}`（文字）、`src/frame_main.cpp`（字段和订阅）。

## 按缩放计算的尺寸

对话框和编辑框里约 50 处写死的像素尺寸（列表框、输入框、按钮的初始宽高）改为 DIP（`DipSize`，`src/utils.h`），颜色按钮的大小和色块也按 DIP 计算。

- 在 GTK 和 macOS 上 wxWidgets 的 DIP 与逻辑像素相同，这些改动不改变外观；主要影响 Windows 的 125%、150%、175% 缩放。
- 没有改：颜色选择器的色谱（256 像素对应 256 级颜色）、视频区和音频区内部的像素计算、启动页（原本就按 DIP）。

## 没有做

- **编辑框分组**：编辑框已经分成三行（注释 / 样式 / 说话人 / 特效，图层 / 时间 / 边距，格式按钮），窄窗口下也不会挤成一行。再重排的收益小，还会改变老用户熟悉的位置，所以没有改。
- **每项设置的说明文字**：没有给首选项逐项添加说明。
- **其他对话框逐个整理**（按钮顺序、间距、说明位置）：没有做。
- Windows 高缩放下的效果没有实际查看，本机只有 GTK。
