# 主界面与首选项

阶段 4 的改动：首选项搜索、字幕网格的外观、状态栏和按缩放计算的尺寸；之后编辑框也重新排过（见“编辑框”）。

## 首选项页面的排版

首选项窗口改成现代设置页的样子：左边是页面列表，右边是当前页（`PreferencesBook`、`OptionPage`，`src/preferences_base.{h,cpp}`）。

**页面列表**
- 自绘列表，代替原来系统的树形列表：子页缩进；当前页底色带一点强调色，左边一道强调色竖条，文字用强调色加粗；悬停时浅色底。可以用上下方向键切换。
- 搜索框在列表上方，找到几项的提示在搜索框下面。
- 记住上次打开的页（`Tool/Preferences/Page`，按页序号）。页面顺序变了，升级后第一次打开可能落在别的页。

**按用途分页**

| 页 | 分组 |
| --- | --- |
| 常规 | 启动（检查更新、自动打开关联文件）、文件（保存界面状态、撤销步数）、最近使用列表 |
| 　默认样式 | 新建和导入时用的样式库 |
| 外观 | 主题、工具栏（显示、经典工具栏、经典彩色图标、图标大小） |
| 　颜色 | 不变 |
| 编辑 | 编辑框（含字体、字典路径）、字数统计、翻译助手 |
| 字幕栏 | 选项（点击时聚焦、高亮可见行、隔行底色、隐藏标签符号、字体） |
| 音频 | 操作、时间、吸附、显示、音频标签字体 |
| 视频 | 播放、视频显示（视觉工具、默认缩放、三种滚轮动作、截图路径）、脚本分辨率、布局分辨率、YCbCr 矩阵 |
| 快捷键 | 原来是“界面”的子页，现在是单独一页；“新建 / 编辑 / 删除”改成 `FlatButton` |
| 备份、自动化、高级（音频、视频） | 不变 |

原来的“界面”页拆进了外观、编辑、字幕栏三页。

**每一行**
- 每组是一个粗体小标题加一条细线，下面每个设置占一行：最左边是标记，然后是名称，右边是控件。控件在每一页都排成同样宽（220 DIP）的一列。
- 是 / 否的设置是自绘勾选框（`FlatCheck`），标签就是勾选框自己的，点文字也能勾。
- 数字是自绘输入框（`FlatFrame` 里的无边框文本框），可以直接输入，也可以在上面滚动滚轮按步长加减。超出范围的输入不采用，离开时显示回已采用的值。
- 列表用 `FlatChoice`，文字用 `FlatFrame`，“浏览…”“选择…”用 `FlatButton`，颜色仍是原来的颜色按钮。
- 不容易看懂的设置在名称下面多一行淡色说明（`OptionAddArgs::help`，`OptionChoice` 的 `help` 参数），目前有十几项。说明也参与搜索。
- 说明文字（主题下的重启提示、默认样式页的说明）用 `OptionPage::Note`。`CellSkip` 不再需要，现在什么也不做。
- 每页都能竖向滚动；窗口不按最高的一页撑高，最多 680 DIP。页面背景用 `theme::UseSurface`，和自绘控件填的底色一致。
- 在输入框里按回车或点别处，焦点留在首选项窗口里；`flat::LeaveField` 只在同一个窗口里把焦点送回字幕文本框。打开窗口时焦点在搜索框。

**改动标记和恢复默认值**
- 值不是默认值的设置（以前改过的，或者这次在窗口里改的）前面有一个强调色小圆点。鼠标移上去变成 ↺，点一下恢复这一项的默认值（`OptionPage::Reset`）。
- 恢复也和窗口里的其他修改一样：按“确定”或“应用”生效，按“取消”放弃。勾选框恢复时会发出它的事件，所以依赖它的设置（例如“自动保存”下的间隔和路径）会一起启用或停用。
- 默认值取自选项本身（`agi::OptionValue*::GetDefaultValue`，`libaegisub/include/libaegisub/option_value.h`）。
- 底部按钮改成“恢复本页默认值”（`Preferences::RestorePageDefaults`）：只恢复当前页的设置，同样要按“确定”才生效。在快捷键页，它先确认再恢复默认快捷键（和原来一样立即生效并重新打开窗口）。原来一次重置所有设置的做法去掉了。

**搜索**
- 页面列表里有匹配的页加粗，右边胶囊里显示匹配几项；没有匹配的页变灰。
- 切到一页（自动切换、回车、点列表）时，页面滚动到这页第一个匹配的设置。

## 首选项搜索

首选项窗口顶部有搜索框，输入设置的名称、拼音全拼或拼音首字母（例如“音频”可以输 `yinpin` 或 `yp`），大小写和空格不计。

- 匹配的设置标签加粗并用强调色显示；左侧有匹配的页面加粗并显示匹配数，没有匹配的页面变灰。
- 当前页没有匹配时自动切到第一个有匹配的页面；按回车或放大镜依次切到下一个有匹配的页面。
- 搜索框旁边显示找到几项、分布在几页；没有匹配时显示“没有匹配的设置”。
- 页面名称本身也参与匹配，例如搜“快捷键”会找到快捷键页（这一页的内容是列表，列表里的命令请用该页自己的搜索框）。
- 分组标题（如“音频栏”）也参与匹配，匹配时同样变色。

实现：`src/preferences.cpp`（`Preferences::IndexPages`、`Search`），拼音和规范化沿用命令面板的 `palette::MakeKeys` / `NormaliseQuery`。

## 字幕网格

- **隔行底色**：普通行每隔一行略深一点（由“标准前景色”按 4%，深色下 5% 混合进背景色得到，所以用户自定义的网格颜色照样生效）。可在“首选项 → 界面 → 网格 → 隔行加底色”关闭（`Subtitle/Grid/Alternate Rows`）。
- **扁平样式**：表头和行号列不再是蓝色、绿色，改为接近背景的浅灰（深色下比背景略亮），表头文字比正文淡。表头里列与列之间画上下留空的短分隔线，下面一条细线；正文区的列分隔线比行分隔线更淡，只有行号列右边用正常的行线颜色；网格四周不画外框。
- **注释行变淡**：未选中的注释行文字保留 60%（与行底色混合），行号列的“闭眼”图标同样变淡。选中后恢复选中文字色。
- **选中行描边**：选中的行外面画一圈 1 DIP 的蓝色边框（“当前行边框”的颜色，默认是强调色），相邻的选中行合成一个框，画在分隔线之上。
- **旧默认颜色复位**：配置文件会把所有选项都存下来，包括默认值。默认颜色改了以后，存着旧默认值的网格颜色会被当成用户自己改的，深色外观下也不再换成深色（表现为深色界面里网格仍是浅蓝表头、浅色行）。启动时（`theme::Init`）凡是等于原版或上一版默认值的网格颜色都恢复默认；用户真正改过的颜色不动。
- **行号变淡**：未选中的行号保留 68%（与行号列底色混合），选中行和当前行的行号用正文颜色。
- **选中与当前行**：选中行的底色铺满整行（包括行号列）。当前行的底色比其他选中行再深一点（向“当前行边框”颜色混合 12%，深色下 16%），最左侧画一条 3 DIP 宽的竖条，颜色就是“当前行边框”（默认是强调色）。原来的整行边框不再画。
- **行高与内边距**：行高 = 字体高度 + 8 DIP（文字上下各 4 DIP，原来各 2）。单元格左右内边距各 8 DIP（原来约 4 / 6 像素），居中的列按文字实际宽度居中，表头文字也一样。
- **胶囊标签**：CPS 超限的红色底和图层列的绑定组色块不再填满格子，而是左右各缩进半个内边距的圆角胶囊；CPS 胶囊上的文字随超限程度由正文颜色渐变为白色。
- **默认颜色**：网格的浅色出厂值（`default_config.json`）和深色出厂值（`src/theme.cpp`）都改为这套中性灰加强调色蓝的配色。没改过的颜色跟着新默认值走，改过的颜色保持不变。首选项里的颜色项没有变化，“当前行边框”现在决定的是当前行的竖条和底色。

实现：`src/base_grid.cpp`（`BaseGrid::Draw`，由 `OnPaint` 调用）、`src/grid_column.{h,cpp}`（`GridColumn::cell_padding`、`TextLeft`，`DrawPill`）。测试按 `BaseGrid::LineHeight()` 计算点击位置，不再自己按字体高度推算。

## 状态栏

主窗口状态栏分四栏：菜单帮助、临时消息（原有）、**当前行**、**文件状态**。

- 当前行：`第 12 行，共 340 行 · 0:01:02.34 → 0:01:05.00`；多选时加“（选中 3 行）”。没有当前行时为空。
- 文件状态：有对比打开时显示“正在与 other.ass 对比”，否则显示“未保存的更改”或“没有未保存的更改”。
- 在当前行、选择、字幕内容、保存和对比标签变化时更新。对比标签的变化通过新加的 `WorkspaceTabs::AddChangeListener` 通知。

实现：`src/status_info.{h,cpp}`（文字）、`src/frame_main.cpp`（字段和订阅）。

## 视频进度条与下方控件

进度条和下面一行改成与内容块一致的扁平样式，颜色都由块颜色、文字色和强调色混合得到（`theme::Mix`），浅色、深色下都适用，切换外观时立即重绘。

**进度条**（`src/video_slider.cpp`）：

- 细轨道（4 DIP，鼠标悬停时 6 DIP），已播放部分用强调色，其余为灰色。轨道两端各留 10 DIP，滑块在首尾帧也完整可见、可点到。
- 圆形滑块（6 DIP，悬停时 7 DIP），外围一圈块颜色把它和已播放部分分开；获得焦点时再加一圈淡强调色外环，代替原来的点线框和青色方块；当前帧是关键帧时滑块中心挖空。
- 关键帧是轨道上方的淡色短刻度（仍受“显示关键帧”选项控制）。
- 进度条高 26 DIP，轨道中线离底边至少 11 DIP：滑块最大时（悬停并且有焦点外环，半径 10 DIP）也完整画在进度条里，不会被下面一行切掉。原来高 22 DIP，悬停加外环时底部被切掉。
- **当前行的时间范围**：当前行从开始帧到结束帧，在轨道后面画一段淡强调色的底，一眼能看出播放位置和这一行的关系。没有当前行或没有视频时不画。
- 悬停提示显示鼠标所在位置的时间和帧号；拖动时不更新提示。
- **拖动跟手**：拖动时每次移动都立即重绘滑块（`Update()`），再跳转视频。原来只标记待重绘，鼠标移动事件不断到来时重绘一直排在后面，滑块会比视频画面晚到。
- 点击跳转、Shift 点击吸附关键帧、滚轮逐帧 / Shift 滚轮跳关键帧、键盘操作都不变。

**下方一行**（`src/video_box.cpp`、`src/video_time_label.cpp`、`src/video_zoom_control.cpp`）：左边是两个时间读数，中间是播放按钮，右边是自动滚动开关和缩放控件。四周和控件之间的间距都是 `BlockGap`。

- **播放按钮居中**：播放、播放当前行两个按钮放在整行（也就是视频）的正中。视频太窄、正中会碰到两边时，放在左右两组之间空白的中间（`CentredRowSizer`）。大约视频宽 700 像素以上时能正好居中。
- **播放 / 暂停合一，去掉停止按钮**：播放按钮本来就是开关（播放中再按就停），现在播放时图标变成暂停，菜单里的名字变成“暂停”。停止命令（`video/stop`）和它的快捷键仍然保留，只是不在工具栏上。实现方式：命令可以声明 `COMMAND_DYNAMIC_ICON`，提供 `IconFor(context, ...)`；工具栏在空闲时检查 `IsActive`，状态变了就换图标（`src/command/command.h`、`src/toolbar.cpp`）。
- **自动滚动开关**从播放按钮那组移到右边一组（工具栏布局 `video/options`）。
- 两个时间读数原来是只读文本框，现在直接画在块上。数字按等宽格子排，宽度按样例固定，播放时文字和后面的控件都不会跳动（内容超长时只变宽，不变窄）。
  - 宽度用和绘制相同的方式量（经由图形上下文 `wxGCDC`；它量出的文字可能比普通 DC 宽），变宽时整个窗口重新布局。原来用普通 DC 量、只重排父窗口，相对时间位数多时（如 `−3600000ms`）末尾会被截掉。
- **位置读数**：时间（`0:00:02.000`）、淡色帧号，当前帧是关键帧时后面显示强调色的 `K` 标记（代替原来整个文本框借用网格选中色；悬停提示里说明了 K 的意思）。`K` 按字形实际着墨的范围居中（字形框包含下伸部分的空间，按框居中大写字母会偏上），标记本身对齐数字着墨的中线。
  - **时间和帧号分开编辑**：单击时间编辑时间，单击帧号编辑帧号；悬停时只有鼠标下面那一部分显示浅色底。输入框只盖住被点的那部分。帧号部分只接受纯数字。
  - **点别处就退出编辑**：输入期间装一个全局事件过滤器，在输入框以外任何地方按下鼠标（包括视频画面、进度条、画出来的控件这些不接受焦点的地方，原来点这些地方输入框不会关）就取消编辑；点读数的另一部分则直接开始编辑那一部分。
  - **单击就地输入**：不再弹出“跳转到”对话框。这次点击由读数自己处理，读数本身也不接受键盘焦点；否则工具包会在点击之后把焦点交给读数，输入框一失去焦点就收起，看起来就是“无法编辑”（Windows 上 wx 对没处理的左键按下会这样做）。单击后读数变成一个输入框（只在编辑时是输入框），里面是当前时间并已全选。输入纯数字是帧号，带 `:` 或 `.` 的是时间（`0:01:23.456`、`1:23`、`83.5` 秒都可以）。回车跳转并变回读数；Esc 或点别处取消。输入无效时响一声，输入框保持打开。帧号超出范围时跳到首帧或末帧。编辑结束后键盘焦点回到进度条。
  - 输入框在创建时就建好并隐藏，读数一开始就和它一样高，所以切换时这一行不会变高。
  - 右键菜单可复制时间或帧号。
- **相对时间读数**：距当前行开始、结束的毫秒数，整体淡色，负数用真正的减号“−”。悬停提示详细说明两个数的含义和正负（之前 / 之内 / 之后），以及在镜头切换处对时间轴的用法。右键“复制”得到原来的 `+120ms; -880ms` 格式（ASCII）。没有当前行或没有视频时显示“—”。
- **缩放控件**：原生下拉框换成一个圆角的分段控件 `− 75% ▾ +`。
  - 单击中间的百分比弹出预设：25%、50% …… 300%，每 25% 一档，都是整数，当前一档打勾。
  - `−` / `+` 保留原来的梯度：每次 12.5%，范围 12.5%–1000%。菜单和快捷键里的放大、缩小命令，以及 Ctrl+滚轮，也都和原来一样。鼠标在控件上滚动滚轮也按同样的梯度缩放，向上放大。所以中间也可能显示 87.5% 这样的值；分离视频窗口自由缩放时，显示到一位小数。
  - 主工具栏上的“放大视频”“缩小视频”按钮移到这里，主工具栏从 15 个按钮减到 13 个（经典主工具栏不变）。

## 编辑框

文字格式交给右侧的样式面板以后，编辑框只留下行本身的字段，排成两行，外观和样式面板一致：圆角扁平框、框内淡色标签、获得焦点时边框变成强调色，浅色和深色都按主题取色。

```
┌──────────────────────────────────────────────────┐
│ 文本框                                   23 / 40 │
└──────────────────────────────────────────────────┘
☐ 注释  [Default ▾]  [说话人   ▾]  [特效 ▾]     ☐ 对照原文
层 0   开始 0:00:00.00 → 结束 0:00:05.00  时长 0:00:05.00  [时间|帧]
```

- **第一行：这行是什么**——注释、样式、说话人、特效，右端是“对照原文”。紧挨文本框，打完字按 Tab 就到。
- **注释、对照原文是自绘勾选框**（`FlatCheck`，`src/flat_controls.{h,cpp}`），和样式面板里填充、描边等行前的勾选框同一种画法（`flat::DrawCheck`）：圆角方框，勾上时填强调色并画勾。点击不抢走文本框的焦点；Tab 到它上面时按空格切换；Alt+C 仍然切换注释（标签里的助记键）。
- **第二行：在哪一层、什么时候**——图层在最前面（叠字、特效都靠它，是常用的重要字段），然后是开始 → 结束、时长、时间 / 帧开关。默认在最下面，紧挨字幕列表，打轴时和列表里前后几行的时间对照最近。
- **样式**：自绘的下拉框，悬停时显示样式名（名字较长被截断时也能看全）。单击、空格、回车或 Alt+↓ 打开列表；鼠标停在上面滚动滚轮、或按上下键，在样式之间逐个切换（不用先点它，也不用打开列表），一秒内连续切换只算一步撤销。原来旁边的“编辑”按钮去掉了，样式编辑器从样式面板的 “…” 打开。
- **说话人、特效**：扁平文本框，没有内容时显示淡色的“说话人”“特效”。右边的 ▾ 列出文件里已有的值。打字时下面弹出自绘的候选列表（`FlatSuggest`，代替系统的自动补全下拉框）：列出文件里以已输入内容开头、比它长的值（不分大小写，最多 8 个），已输入的部分用正常颜色、补上的部分略淡；圆角浮层，深色下比块颜色略亮，浅色下为白色；选中项用强调色淡底。↑↓ 循环选择，回车或 Tab 采用（Tab 同时到下一个字段），点击采用，Esc 关闭；文本框始终保持焦点。特效框比说话人窄：它常用的值很少。
- **时间**：三个框带淡色标签“开始”“结束”“时长”，开始和结束之间有 →；时长的数字较淡，表示它是算出来的（改时长会移动结束时间）。输入方式（覆盖输入、上下键、粘贴）不变。编辑框太窄放不下标签时，三个标签自动省掉，→ 和悬停提示仍然说明哪个是哪个，保证这一行不被截断。
- **图层**：带淡色标签“层”的扁平框，取代原来的 `0 − +` 数字框。
  - 直接输入数字，回车或离开时生效；不是数字时恢复原值。
  - 拖动“层”字、滚动滚轮、按上下键：每个选中的行在**各自原来的层**上加减（0、1、2 拖 +1 变成 1、2、3），保留彼此的层次，不小于 0。一次拖动、一秒内的连续滚动或按键各算一步撤销。
  - 选中的行不在同一层时显示“—”。
  - 悬停提示说明图层的作用：数字大的画在上面，只有同一层同时出现的行会互相避让。
- **离开输入框**：在说话人、特效、图层、三个时间框里按回车，确认输入并离开这个框，回到字幕文本框（不再跳到下一行）；在框外任何地方点一下也一样离开（点另一个输入框则直接进入那个框）。样式面板里的数字输入框同样如此。实现在 `flat_controls.cpp` 的事件过滤器（`flat::AddField`、`flat::LeaveField`），它也负责把滚轮发给鼠标下的下拉框（`flat::AddWheelTarget`）。
- **字数**：从第一行的数字框挪到文本框右下角，显示成“已用 / 上限”（如 `23 / 40`），超过上限时变成红底；上限为 0（不检查）时只显示字数。文本框右边留出它的宽度，文字不会被挡住。悬停提示按当前设置说明怎么数（按 `\N` 分行取最长一行，不算 `{}` 里的标签，是否算空格和标点）；单击打开首选项并搜索“字数统计器”。
- **对照原文**（原“显示原始字幕”）：在文本框上方显示切到这一行时的文字，只读。上方有淡色标题“原文 · 切到此行时的内容”，背景和可编辑的文本框不同；四个按钮里“还原”改名“还原为原文”。四个按钮是自绘按钮（`FlatButton`，`src/flat_controls.{h,cpp}`），和动画页的“整行 / 前半 / 后半”同一种画法：圆角底色、细边框，悬停加深；点击不抢走文本框的焦点。悬停提示说明它是什么、什么时候更新、四个按钮做什么。
- **去掉的按钮**：B / I / U / S、字体、四个颜色按钮、✓、“编辑”。样式面板有同样的功能（次要颜色在外观区的“卡拉OK”一行）。对应的命令（`edit/style/bold`、`edit/color/primary`、`edit/font` 等）仍然注册，快捷键和菜单照常可用。
- **✓ 按钮**是“下一行”命令（`grid/line/next/create`）：在编辑框里按回车（或小键盘回车）做的是同一件事——确认当前行，跳到下一行，已经是最后一行时在后面新建一行并跳过去。命令和快捷键不变，音频计时里的确认也照常调用它。
- **边距**移到样式面板的变换区，见 [style-panel.md](style-panel.md)。
- **时间 / 帧切换**：原来两个单选按钮（`T&ime` / `F&rame`，带 Alt+I / Alt+R 助记键）换成时间框旁边的一个自绘分段开关“时间 | 帧”，样子和视频下方的缩放控件一样，选中的一半用强调色。它同时决定编辑框的时间框和字幕网格显示时间还是帧号。没有视频或时间码时“帧”变灰、点不了，已经是帧时退回时间。开关不接受焦点，不再有助记键。
- **字段在文本框下方**：默认放在文本框下面。Tab 顺序跟着位置：文本 → 注释 → 样式 → 说话人 → 特效 → 对照原文 → 图层 → 开始 → 结束 → 时长。可以在“首选项 → 界面 → 编辑框 → 行属性放在文本框下方，靠近字幕列表”（`Subtitle/Edit Box/Fields Below Text`）关掉，字段回到文本框上面（两行的上下顺序不变），改了立即生效。

实现：`src/subs_edit_box.{h,cpp}`（`ArrangeRows`、`FitTimeLabels`、图层的 `ShiftLayers`）、`src/flat_controls.{h,cpp}`（`FlatFrame` 把一个无边框的原生输入框放进圆角框，`FlatChoice` 是自绘下拉框，`FlatBadge` 是字数角标）、`src/time_unit_toggle.{h,cpp}`。

窗口右侧一整列，显示正在编辑的文字的样式、字体、对齐、填充、描边、背景和阴影，见 [style-panel.md](style-panel.md)。

## 按缩放计算的尺寸

对话框和编辑框里约 50 处写死的像素尺寸（列表框、输入框、按钮的初始宽高）改为 DIP（`DipSize`，`src/utils.h`），颜色按钮的大小和色块也按 DIP 计算。

- 在 GTK 和 macOS 上 wxWidgets 的 DIP 与逻辑像素相同，这些改动不改变外观；主要影响 Windows 的 125%、150%、175% 缩放。
- 没有改：颜色选择器的色谱（256 像素对应 256 级颜色）、视频区和音频区内部的像素计算、启动页（原本就按 DIP）。

## 没有做

- **每项设置的说明文字**：只给十几项不容易看懂的设置加了说明，没有逐项都加。
- **其他对话框逐个整理**（按钮顺序、间距、说明位置）：没有做。
- Windows 高缩放下的效果没有实际查看，本机只有 GTK。
