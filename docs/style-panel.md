# 样式面板

主窗口右侧的一整列，参考 Premiere 的“基本图形”面板。顶部是分段切换“样式 | 动画 | 时间”，右边是收起按钮 »：
- “样式”页是下面各分区；
- “动画”页编辑当前行的 `\move`、`\fad` / `\fade`、`\t` 和 `\org`（见下面“动画页”）；
- “时间”页是当前行的开始、结束、阅读速度、附近的画面切换、前后余量，连接相邻行和平移，以及整个文件的问题检查（见下面“时间页”）。

切换时各分区保持原来的展开 / 折叠状态（`StylePanel::ShowPage`）。面板记住最后显示的是哪一页（`App/Style Panel/Page`），下次打开回到这一页。切换条太窄放不下文字时，文字以省略号结尾，不会互相压住。

“样式”页直接显示正在编辑的文字是什么样子，包括样式、字体、字号、对齐、填充、描边、背景、阴影和位置、缩放、旋转，并且可以直接修改。

## 位置

- 面板在编辑区右侧，占满整个高度；对比标签页里没有它。
- 面板左边的空隙就是拖动条，可以左右拖动改变宽度：默认 280 DIP，范围 220–600 DIP。宽度保存在 `App/Style Panel/Width`。
- “视图”菜单里的“隐藏样式面板 / 显示样式面板”（命令 `app/toggle/style_panel`）控制是否显示，状态保存在 `App/Style Panel/Show`，默认显示。
- 窗口宽度不到 1100 DIP 时面板自动收起，不改变上面的选项；窗口变宽后自动回来。
- 面板右上角的 `»` 按钮把面板收起：窗口够宽时等于从菜单隐藏（关掉上面的选项）；在窄窗口里手动点开的面板，则回到自动收起的状态。
- 面板收起（自动收起、`»` 或从菜单隐藏）时，右边留一条窄条（块间距加 24 DIP 宽），像收起的侧边栏一样画成单独的一块：内侧一道强调色竖线，顶部 `«`，下面竖排三页的名字“样式”“动画”“时间”，上次停留的那页用强调色，衬一块浅强调色的圆角底（不用粗体：Windows 上旋转的中文粗体会发虚）。点一个名字就展开面板并切到那一页，悬停的名字变成强调色；点窄条的其他地方展开到上次停留的那页。窄窗口里点开的面板会一直开着，直到窗口变宽再变窄；从菜单选“显示”也会在窄窗口里打开。
- 分区（样式、图形、文本、外观、变换）点标题可以折叠；一开始都是展开的。图形区只在当前行是图形时出现。
- 分区标题的折叠箭头和正文的控件左边对齐；箭头和标题按文字实际着墨的中线垂直居中（按字形框居中时，Windows 上的标题会偏下、箭头显得偏上）。

不做成标签页，是因为面板要和编辑框、视频、字幕列表同时看得到：面板显示的是编辑框里选中的文字，拖数值时要看画面。

## 显示的是什么

| 当前选择 | 面板显示 |
|---|---|
| 编辑框里选中了一段文字（只选一行时） | 这段文字开头处的样子 |
| 没选文字，选中一行 | 这一行开头处的样子 |
| 选中多行 | 各行开头处的样子；各行不同的项显示 `—`，开关显示为半选 |
| 没有选中的行 | 全部显示 `—` |

样式名单独占一行，下一行左边是灰字，右边是四个按钮。灰字写着面板描述的是哪一种（选中的文字、当前行、所选的 n 行）。只选中了标签、没有选中文字时，按“没选文字”处理。

“某处的样子”的算法（`src/style_look.cpp`，`LookAt`）：

- 从行的样式开始，依次应用这个字符之前的覆盖标签，紧挨在它前面的标签也算。行首的标签算在第 0 个字符之前。
- `\r` 回到行的样式，`\r名称` 换成那个样式，找不到时按行的样式处理。
- 标签不带值（如 `\fs`）时恢复为样式的值。
- 对齐只看整行第一个 `\an` / `\a`，不论它在哪里，和渲染器一致。
- `\t(...)` 里的标签不算：那是动画的终点，不是静态的外观。
- 找不到样式时按新建样式的默认值处理；`{注释}` 不算文字。

## 修改

改动写成覆盖标签，范围和显示的一致：

- **选中了一段文字**（只选一行时）：标签写在这段文字前面；如果后面还有文字，在这段文字后面写回原来的值。选区里同一项的其他标签删掉。改完后选区仍然是这段文字。
- **没选文字**：改所选的每一行。标签写在行首（行首已有标签块就写进去），行里同一项的其他标签删掉。改出来的值和行的样式相同时，不留标签。
- **对齐**总是作用于整行，即使选中了文字。点水平按钮时，每行保留自己的垂直方向，反之亦然。
- `\t(...)` 里的标签和 `{注释}` 不动；标签块里其他标签保持原样（逐字保留，不重新格式化）。
- 所有修改都通过编辑门写入，对比打开时不会修改；每次修改是一步撤销。

控件：

- **按钮**（B / I / U / S、对齐）：点一下切换。B / I / U / S 用的就是原来编辑框里那几个按钮的图标（`edit/style/bold` 等命令的图标，跟着单色 / 经典图标设置和深浅色变化）；对齐按钮的图标也加进了同一套单色图标（`align_left` … `align_bottom`），笔画粗细和颜色一致。半选状态的图标变淡。半选状态点一下变成全部打开。点按钮不会抢走编辑框的焦点，编辑框里的选区保持不变。
- **数字**（大小、字间距；蓝色的数字）：左右拖动改值，按住 Shift 微调（十分之一）；一次拖动只算一步撤销，拖动时视频实时更新。单击则变成输入框，回车确认，Esc 取消，输入的不是数字时响铃并保持打开；回车、Esc 或点击别处之后键盘回到字幕文本框。超出范围的值会被限制在范围内（大小 1–1000，字间距 −100–100）。
- **字体**：单击弹出列表，可以输入搜索，上下键选择，回车或单击确定；回车时如果列表里没有匹配的字体，就使用输入的名称。
- **滚轮**：鼠标停在样式、字体、字重这几个下拉框上滚动滚轮，不用先点它、也不用打开列表就能逐个切换（在 Windows 上滚轮本来只发给有键盘焦点的控件，这里改为发给鼠标下的下拉框）：样式和字体按列表顺序，向上是上一个；字重每格 100，向上更粗，各行保留自己的倾斜。一秒内的连续滚动只算一步撤销。滚轮正在滚动面板时，滚过下拉框不会改它的值（刚停下 0.4 秒内也一样），只有停下后在下拉框上再滚才切换，避免滚动面板时误改。
- **字重**：单击弹出菜单：常规、斜体、粗体、粗斜体，以及 100–900 的其他字重（保留各行原来的倾斜）。字重和倾斜一起改时只算一步撤销。
- **填充 / 卡拉OK / 描边 / 阴影**：点勾选框（或名称）显示或隐藏，点色块打开取色器。卡拉OK 是次要颜色（`\2c`、`\2a`）：卡拉 OK 标签的文字唱到之前的颜色，原来在编辑框的颜色按钮里，现在在填充下面一行。
  - 隐藏：填充和卡拉OK设为完全透明（`\1a&HFF&`、`\2a&HFF&`），描边设宽度 0，阴影设距离 0，不删除颜色标签，随时可以勾回来。
  - 显示：恢复样式的值（样式本身没有描边或阴影时用 2 像素），颜色完全透明的同时恢复为样式的不透明度（样式也透明时用不透明）。
  - 样式用了不透明底框时描边无法显示，勾选描边会响铃。
- **取色器**：就是原来编辑框颜色按钮用的那个，带不透明度；它的屏幕取色也能从视频画面取色，所以没有另做吸管。拖动时实时预览；预览和原来编辑框的颜色按钮一样，是对所选各行的一次“交互”：取色期间不能开始对比，按“取消”只撤销预览本身，期间别处做的修改不会被撤销。只写改了的部分：只改颜色时，各行原来的不透明度保持不变。
- **阴影的距离、角度和模糊缩进**：这两行在“阴影”下面，左边留出勾选框的宽度，和色块对齐，看得出是从属于上面颜色的设置。
- **数字**：填充、卡拉OK和阴影的不透明度（%，0–100）、描边宽度、阴影距离和角度、模糊，都可以拖动或输入。改距离时每行保持自己的角度（原来没有阴影时用 135°，即右下），改角度时保持距离；横纵偏移相等时写成 `\shad`。
- **背景**：只有样式能设底框（边框样式 3），而改样式会影响用它的所有行，所以勾选时只换所选行的样式：
  - 勾选：给这些行换上一份样式副本，名字是“原名 Box”，除了边框样式为 3 之外和原样式完全相同；原样式和用它的其他行不变。已经有一模一样的样式时直接用它（优先用“原名 Box”），不会重复复制。
  - 取消勾选：换回不带底框的样式。原名以“ Box”结尾且去掉后缀的样式只差边框样式时就用它（也就是换回原来的样式）；否则找一模一样的样式；都没有时复制一份，名字是“原名 No Box”。
  - 名字被占用、内容又不同时，在后面加“ 2”“ 3”等。复制样式和改行的样式是一步撤销。
- **变换**：分成几组，每组上面有一行淡色小标题：位置（X / Y，`\pos`）、边距（左 / 右 / 垂直）、缩放（X / Y，`\fscx`、`\fscy`，%）、旋转和不透明度（并排，各有标题；`\frz` 逆时针为正，`\alpha` 是整体不透明度）。
  - 没有 `\pos` 的行显示它实际所在的位置：按对齐方式、边距（行的边距为 0 时用样式的）和脚本分辨率计算，和渲染器一致；从这个值开始拖。改位置时只改这个方向，另一个方向保持。
  - 用 `\move` 移动的行，位置显示 `\move` 的起点，改位置时这些行保持不变（加 `\pos` 会破坏移动）。
  - 整体不透明度只在填充、描边、阴影的不透明度相同时显示数值，否则显示 `—`。设置后行里的 `\1a`、`\3a`、`\4a` 都换成一个 `\alpha`（`\alpha` 也作用于卡拉OK颜色）。
  - **边距** 左 / 右 / 垂直：行的三个边距字段，原来是编辑框里的三个数字框。行的边距为 0 时使用样式的边距，面板用浅一些的蓝色显示样式的值（不是不可用的灰色）；输入 0 回到样式的边距。范围 0–9999，可以拖动或输入，一次拖动是一步撤销，撤销名称和原来一样（“改变左边距”等）。多行不同时显示 `—`。用 `\pos` 或 `\move` 定位的行不按边距放置，但边距仍可修改（悬停提示里有说明），框始终可用。
- **不留标签的规则**：改出来的值和样式相同时不写标签，但如果去掉标签后行里别的标签仍会改变它（例如 `\alpha` 之后再把填充设回样式的不透明度），就照样写上。
- **样式**：单击样式名弹出文件里的样式列表，选中后应用到所选的行。右边四个按钮：
  - **↑ 用当前行更新样式**：样式改成当前行开头处的外观（样式能保存的项：字体、字号、粗体、斜体、下划线、删除线、字间距、对齐、各颜色和不透明度、描边宽度、阴影、缩放、旋转），所选的、用这个样式的行里因此多余的行首标签被删除。样式存不下的保留在行里：100–900 的其他字重、横纵不同的阴影、模糊。行中间的标签不动。一步撤销，用这个样式的其他行会跟着变。
  - **↓ 恢复为样式**：从所选的行里删除面板能设置的所有标签（包括模糊、缩放、旋转），`\pos`、`\move`、`\clip`、`\fad`、`\t`、卡拉 OK 等其他标签保留。
  - **+ 新建样式**：输入名称（默认是“原样式名 2”这样不重复的名称；重名时提示重新输入，不区分大小写），复制当前行的样式并改成当前行的外观，应用到所选的行，并删掉这些行里因此多余的行首标签。
  - **… 样式编辑器**：打开原来的样式编辑器，修改全部设置（边距、编码、边框样式等）。

- **图形**（只在当前行是 `\p` 图形、并且只选了这一行时出现，在样式区下面）：宽、高。
  - 这就是原来双击图形行打开的“编辑图形”窗口，现在并进了面板：双击图形行、选中后按回车、右键菜单“编辑图形”都会打开面板（收起时展开）、展开图形区并滚动到它。不再弹出窗口。
  - 宽高按旋转前的绘图控制点边界算，以脚本像素计。修改时直接按比例改写路径里的坐标，不加 `\fscx` / `\fscy`，已有的缩放标签换算进路径后删除。可以拖动或输入，一次拖动是一步撤销。
  - 原来窗口里的其他几项在面板的其他分区：位置 X / Y 在变换区（`\pos`），填充颜色和不透明度在外观区（`\1c`、`\1a`），和文字行一样改。
  - 和原来一样，文字与绘图混合、多个绘图块、带 `\move` / `\t` / `\r` 的行不算可编辑的图形。

## 动画页

动画页显示当前行（没有当前行时取选中的第一行）的动画效果，每种效果一张卡片，修改作用于所有选中的行。特效栏里的横幅 / 滚动也是一张卡片，排在最前，只改同类特效的行，见[滚动特效的可视化编辑](scroll-effect.md#动画页的卡片)。顶部写着读的是哪一行、选中了几行，以及这一行的开始和结束时间。

- **时间单位**：所有时间都显示成视频时间 `h:mm:ss.cc`，和字幕表格一致；标签里仍然写相对行开始的毫秒数，换算由面板完成。
  - 时间框可以左右拖动（每 2 DIP 10 毫秒，按住 Shift 时 1 毫秒），也可以点开后输入 `0:01:03.30`。
  - 旁边的时钟按钮把视频当前时间填进去（每行按自己的开始时间换算）；没有打开视频时不可用。
  - 再旁边是同一时间占行长的百分比，可以拖动或输入。多选时，输入时间给每行同样的偏移，输入百分比按每行自己的长度换算。
- **时间条**：每张卡片上方是一条代表整行的时间条（0%–100%，每 25% 一条刻度）。
  - 移动和变换显示一个范围，两端可以拖动；淡入淡出显示不透明度曲线和四个时间点。
  - 拖动时吸附到视频帧（按住 Shift 不吸附），视频同时跳到那个时间，可以直接看到效果；点击条上其他位置让视频跳过去。
  - 视频当前时间在条上显示为一条竖线。
- **移动 `\move`**：起点、终点的 X / Y；准星按钮切换到视频上的拖动工具，直接在视频上拖起点和终点。入点、出点可调，例如出点设为 50%，移动只占行的前一半。“整行 / 前半 / 后半”是常用的范围。标题栏 ✕ 左边的 ⇄ 是倒放：对调起点和终点，时间不变。范围是整行时不写时间（`\move(x1,y1,x2,y2)`）。添加时起点和终点都是行现在的位置；删除时行留在起点（改成 `\pos`）。
- **淡入淡出 `\fad` / `\fade`**：淡入的开始、完全显示，淡出的开始、完全消失，以及之前、中间、之后的不透明度。淡入从行开始、淡出到行结束、不透明度是 0 / 100 / 0 时写 `\fad(淡入, 淡出)`，否则自动写成 `\fade(...)`，比如淡出在行的 50% 处就结束。改一个时间时，其他时间会让开以保持顺序。
- **变换 `\t`**：范围（同上）、加速度（1 匀速，大于 1 先慢后快），以及变化到的属性：字号、横向 / 纵向缩放、三个方向的旋转、字距、边框、阴影、模糊、横向 / 纵向倾斜、不透明度、填充不透明度和三种颜色。添加时取行现在的值，再拖动到目标值。不认识的标签原样保留并显示出来。一行可以有多个 `\t`；只读写行首标签块里的 `\t`，后面文字中间的 `\t` 不动。
- **旋转中心 `\org`**：X / Y；准星按钮切换到视频上的旋转工具。
- **添加效果**：“+ 添加效果”菜单；移动、淡入淡出、旋转中心每行只有一个，已有时菜单项不可用；变换在子菜单里先选要变化的属性。卡片右上角的 ✕ 删除这个效果。
- 每次拖动合并为一步撤销，其他操作各一步。

## 时间页

时间页显示当前行（没有当前行时取选中的第一行）的时间，修改作用于所有选中的行，每次拖动或点击都是一步撤销。原有的入口全部保留：时间后处理器、“平移时间”、“吸附到附近的画面切换”和各个快捷键命令照旧可用，与时间页共用同一份代码和同一组设置，一边改了另一边也能看到。窗口窄于 1100 DIP 时面板会收起，这时用原来的入口。

- **概览**（只读）：
  - 读的是哪一行、选中了几行，以及这一行的开始和结束时间。
  - 阅读速度：“每秒 N 字”，算法和阈值都与字幕表格的 CPS 列相同（首选项 → 界面 → 字数统计）。超过警告阈值时变色、加粗，到错误阈值时是表格里的错误色。行短于 0.1 秒时不计算。
  - 与上一行、下一行的间隔或重叠，按文件顺序，跳过注释行，例如“距下一行 1400 ms”“与上一行重叠 40 ms”。
- **时间**：
  - 开始、结束两个时间框，可以拖动（每 2 DIP 10 毫秒），也可以点开后输入 `0:01:03.30`。有视频时吸附到帧（开始吸到帧的开始，结束吸到帧的结束），按住 Shift 不吸附；拖动时视频跟着跳到那个时间。
  - 多选时，各行移动和当前行同样的量。开始不会晚于结束，结束也不会早于开始。
  - 时钟按钮把开始或结束设为视频当前帧，执行的就是“开始 / 结束吸附到视频”命令。
  - ‹ › 把选中行的开始或结束前后各移一帧，没有视频时不可用。
  - 时长：改时长时结束跟着动，每行得到同样的时长，结束吸附到帧。
- **画面切换**：
  - 开始、结束各一行，显示离最近的切换点差几帧，例如“开始早 10 帧”（切换点在开始之后 10 帧）、“结束晚 2 帧”、“开始在切换点上”；超出距离时显示“开始：500 ms 内没有”。规则和“吸附到附近的画面切换”完全一样：开始对齐切换帧，结束对齐切换前一帧。
  - 每行的“吸附”只移动这一端（选中的所有行都移动这一端）；在切换点上或超出距离时不可用。
  - “两端都吸附”执行“吸附到附近的画面切换”命令，状态栏提示和撤销都和从菜单执行一样。
  - `±` 框是吸附距离，就是“首选项 → 时间 → 吸附画面切换的最大距离”。
  - 还没有关键帧时显示“没有这个视频的画面切换”和“检测画面切换”按钮；关键帧是视频自带的时，显示时间后处理器里那句灰字提示和同一个按钮。
- **前后余量**：
  - 前后余量就是字幕比说话稍早出现、稍晚消失的那段时间（lead-in / lead-out），方便观众读完。
  - “前留”“后留”两个数值框就是时间后处理器“前后余量”一节的两个时长，在这里改了，弹窗里也是这个值。名字不用“提前”，免得和平移卡片的“提前”（整行往前挪）混淆。
  - “+ 前留”“+ 后留”“+ 两头”给选中的行加余量，规则和时间后处理器一样：不越过原本不重叠的相邻行，碰到就停在那一行的边上。没选中的行即使相邻也不动。注释行不加。
  - 快捷键命令“加前留 / 加后留”仍然按首选项 → 音频里的长度、只改音频里当前行，保持不变。
  - 中文界面里“前后余量”的说法统一了：时间后处理器、首选项、菜单命令原来写作“提前开始 / 延后结束”，现在都叫“前留 / 后留 / 前后余量”。
- **连接相邻行**：
  - “间隔”“重叠”“偏向”就是时间后处理器“连接相邻行”的三个设置，两边共用。
  - “连接”把选中的行（跳过注释行，按开始时间排序）里前后相邻、间隔不超过“间隔”或重叠不超过“重叠”的两行接在一起：接点在前一行结束到后一行开始之间，偏向 0% 在前一行的结束处，100% 在后一行的开始处。没选中的行不动。一步撤销。
  - 下面一行灰字预先说明选中的行里有几处会连上；一处都没有或只选了一行时，按钮不可用。
- **平移**：
  - “时间 | 帧”和偏移量就是“平移时间”对话框的设置，两边共用；没有视频和时间码时只能按时间。
  - “提前”“推后”把选中行的开始和结束一起移动，按帧移动时开始、结束各按帧的开始和结束换算，和对话框的结果一致。按下后对话框的方向也记成这一次的方向。一步撤销。
  - 对话框里的“全部行 / 选中行之后”、只移开始或只移结束、平移记录，仍然只在对话框里。
- **检查**（打完轴后查问题，只列出和跳转，不自动修改）：
  - 范围：“全部 | 选中”，检查整个文件或只查选中的行（`Timing/Check/Selection Only`）。
  - 列出五类问题，注释行不查：
    - **太短**：时长短于“最短”（默认 500 ms，`Timing/Check/Min Duration`）；
    - **太快**：阅读速度超过字幕表格 CPS 列的警告阈值，到错误阈值时用错误色；
    - **重叠**：和**同样式**的另一行时间重叠，记在后开始的那一行上（“与 #11 重叠 120 ms”）；不同样式（对白和标牌、上下两排）重叠是正常的，不报。只查选中行时，仍和没选中的行比；
    - **间隔太短**：和**同样式**的上一行之间只空了一点（大于 0、小于“间隔”，默认 100 ms，`Timing/Check/Min Gap`，设为 0 不查），字幕会消失一下又出现，看起来在闪；记在后一行上（“与 #11 间隔仅 50 ms”）。正好接上（间隔 0）不算。用上面的“连接”可以补上；
    - **没对齐切换点**：开始或结束离最近的切换点差 1 到“差帧”帧（默认 3 帧，`Timing/Check/Cut Frames`），多半是想对齐却差了一点；正好在切换点上或差得更远的不报。没有关键帧时不查这一项。
  - “最短”“间隔”一行，“差帧”在下一行。面板窄时数值框先缩短标签，数值和单位总是完整显示。
  - 汇总一行写各类有几处，下面是列表：每条前面是行号，最多显示 8 条，多了用滚轮在列表里滚动。当前行的问题用强调色。
  - 点一条就选中那一行，有视频时跳到问题所在的时间（结束端的问题跳到行尾那一帧）；‹ › 从当前行起跳到前一处、后一处问题。
  - 修好之后列表自动更新。时间页显示在屏幕上时才检查，切到时间页或展开面板时补一次。

## 实现

- `src/style_look.{h,cpp}`：`LookAt(line, plain_pos, find_style)` 计算外观；`PlainPosition` 把编辑框的字节位置换成不算标签的字符位置。
- `src/style_edit.{h,cpp}`：修改。`SetForLine` / `SetForRange` 是纯文本的改写；`Apply` 读取选择、写入并提交，`amend_id` 用来把一次拖动合并成一步撤销。
- `src/style_panel_parts.h`：面板的自绘部件（数字框、按钮、文字按钮、卡片标题、分区标题、分段切换等），三页共用。数字框可以换显示和输入的格式（动画页和时间页用来显示时间）。
- `src/animation_tags.{h,cpp}`：读写 `\move`、`\fad` / `\fade`、`\t`、`\org`，纯文本、不依赖界面。
- `src/timing_page.{h,cpp}`：时间页。改写选中行的时间，提交类型是 `COMMIT_DIAG_TIME`；拖动合并为一步撤销。
- `src/timing_adjust.{h,cpp}`：时间页与原有入口共用的部分。`AddLead` 加余量（时间后处理器传同一组行作为要改的行和边界），`CharactersPerSecond` 计算阅读速度（字幕表格的 CPS 列也用它），`NearestSceneCut` 找开始或结束最近的切换点（规则同 `SnapToKeyframes`），`JoinAdjacent` / `CountJoins` 连接相邻行（时间后处理器也用它），`ShiftTime` 按时间或帧平移一个时间（“平移时间”对话框也用它）。
- `src/timing_check.{h,cpp}`：`FindTimingIssues` 找出检查卡片列的问题，纯函数，不依赖界面。
- `src/animation_page.{h,cpp}`：动画页。改写选中的行时，每行按自己的长度读出动画、修改、再写回对应的标签。
- `src/style_panel.{h,cpp}`：面板。所有部件都是自绘的扁平控件（和视频下方的控件一样），浅色、深色都按主题取色。
  - 选择、当前行、编辑框里的选区或字幕内容变化时，等空闲时重新读一次（打字时每个键都会提交，合并成一次）。
  - `Shown()` 返回每个部件显示的内容，供测试使用。
- `StylePanelEdge`（同在 `src/style_panel.{h,cpp}`）：面板左边的窄条，负责拖动改宽度、按选项和窗口宽度显示或收起面板、收起时点开；面板的 `»` 按钮和图形行要求打开面板时也经过它（`Collapse`、`Open`）。`src/frame_main.cpp` 只是把它和面板放进布局。
- `src/dialog_rectangle.{h,cpp}`：图形。`ShapeSize` 读当前行图形的宽高，`ResizeShape` 改写路径并提交；`EditDrawing` 只是让面板显示图形区。
- `theme::TextInk`（`src/theme.cpp`）：文字实际着墨的行范围，分区标题和视频下方 K 标记的垂直居中都用它。

## 视频上的十字准星坐标

十字准星工具旁边的坐标原来是 Verdana 粗体加四个方向的黑色描边（字体对象一开始无效，找不到时会退成衬线字体）。现在用界面字体（14 像素、中等字重），白字放在半透明黑色的标签上，离十字线 6 像素，仍放在靠视频中心的那个角。实现：`src/visual_tool_cross.cpp`，`OpenGLText` 多了按 `wxFont` 设字体和不描边的绘制。

## Windows 上的深色模式

Windows 只在程序启动时决定自带控件（输入框、下拉框、列表、滚动条等）用浅色还是深色，运行中改主题时这些控件不会变，自绘的部分（包括这个面板）会马上变。所以在 Windows 上，从首选项改了主题、关闭首选项后，如果自带控件的深浅和新主题不一致，会询问是否现在重启 Aegisub（同一次改动只问一次）；选“是”会先关闭主窗口（有未保存的修改时照常询问），再重新启动。其他系统上不会询问。

## 没有做

- **浮动面板**：不能拖出主窗口放到第二块屏幕上。
- **检查的一键修正**：检查只列出和跳转，修正用时间页上面的卡片；不做“全部吸附”“全部连接”这类一键修正，免得误改。
- **行距、字偶距、全大写、上下标、段落方向、文本蒙版**：ASS 没有对应的功能。
- **单独的吸管按钮**：取色器自带的屏幕取色已经能从视频取色。
- **`\move` 行的位置**：样式页的位置框没有做成同时平移起点和终点；在动画页里分别改。
- **按比例跟随行长**：行的时长改变后，动画里写死的时间不会按比例重新计算（整行范围的 `\move`、`\t` 不写时间，会自动跟随；`\fad` 的淡出也总是到行尾）。
- **准星按钮直接取点**：准星按钮是切换到视频上的拖动 / 旋转工具，不是“点一下视频取一个坐标”。
- **整体不透明度的乘法**：ASS 的 `\alpha` 是直接设置，不能像设计软件那样按比例叠加在各部分的不透明度上。
- 真实鼠标拖动、取色器里的屏幕取色、字体弹出列表的键盘操作，在这个 Wayland 环境里无法自动模拟，只在事件层面测试过（同视频控件）。
