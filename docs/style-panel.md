# 样式面板

主窗口右侧的一整列，参考 Premiere 的“基本图形”面板：直接显示正在编辑的文字是什么样子，包括样式、字体、字号、对齐、填充、描边、背景和阴影，并且可以直接修改。

## 位置

- 面板在编辑区右侧，占满整个高度；对比标签页里没有它。
- 面板左边的空隙就是拖动条，可以左右拖动改变宽度：默认 280 DIP，范围 220–600 DIP。宽度保存在 `App/Style Panel/Width`。
- “视图”菜单里的“隐藏样式面板 / 显示样式面板”（命令 `app/toggle/style_panel`）控制是否显示，状态保存在 `App/Style Panel/Show`，默认显示。隐藏后，拖动条留下来作为右边距。
- 三个分区（样式、文本、外观）点标题可以折叠。

不做成标签页，是因为面板要和编辑框、视频、字幕列表同时看得到：面板显示的是编辑框里选中的文字，拖数值时要看画面。

## 显示的是什么

| 当前选择 | 面板显示 |
|---|---|
| 编辑框里选中了一段文字（只选一行时） | 这段文字开头处的样子 |
| 没选文字，选中一行 | 这一行开头处的样子 |
| 选中多行 | 各行开头处的样子；各行不同的项显示 `—`，开关显示为半选 |
| 没有选中的行 | 全部显示 `—` |

样式名下方的灰字写着面板描述的是哪一种（选中的文字、当前行、所选的 n 行）。只选中了标签、没有选中文字时，按“没选文字”处理。

“某处的样子”的算法（`src/style_look.cpp`，`LookAt`）：

- 从行的样式开始，依次应用这个字符之前的覆盖标签，紧挨在它前面的标签也算。行首的标签算在第 0 个字符之前。
- `\r` 回到行的样式，`\r名称` 换成那个样式，找不到时按行的样式处理。
- 标签不带值（如 `\fs`）时恢复为样式的值。
- 对齐只看整行第一个 `\an` / `\a`，不论它在哪里，和渲染器一致。
- `\t(...)` 里的标签不算：那是动画的终点，不是静态的外观。
- 找不到样式时按新建样式的默认值处理；`{注释}` 不算文字。

## 修改

改动写成覆盖标签，范围和显示的一致：

- **选中了一段文字**（只选一行时）：标签写在这段文字前面；如果后面还有文字，在这段文字后面写回原来的值。选区里同一项的其他标签删掉。改完后选区仍然是这段文字。
- **没选文字**：改所选的每一行。标签写在行首（行首已有标签块就写进去），行里同一项的其他标签删掉。改出来的值和行的样式相同时，不留标签。
- **对齐**总是作用于整行，即使选中了文字。点水平按钮时，每行保留自己的垂直方向，反之亦然。
- `\t(...)` 里的标签和 `{注释}` 不动；标签块里其他标签保持原样（逐字保留，不重新格式化）。
- 所有修改都通过编辑门写入，对比打开时不会修改；每次修改是一步撤销。

控件：

- **按钮**（B / I / U / S、对齐）：点一下切换。半选状态点一下变成全部打开。点按钮不会抢走编辑框的焦点，编辑框里的选区保持不变。
- **数字**（大小、字间距；蓝色的数字）：左右拖动改值，按住 Shift 微调（十分之一）；一次拖动只算一步撤销，拖动时视频实时更新。单击则变成输入框，回车确认，Esc 取消，输入的不是数字时响铃并保持打开。超出范围的值会被限制在范围内（大小 1–1000，字间距 −100–100）。
- **字体**：单击弹出列表，可以输入搜索，上下键选择，回车或单击确定；回车时如果列表里没有匹配的字体，就使用输入的名称。
- **字重**：单击弹出菜单：常规、斜体、粗体、粗斜体，以及 100–900 的其他字重（保留各行原来的倾斜）。字重和倾斜一起改时只算一步撤销。
- **填充 / 描边 / 阴影**：点勾选框（或名称）显示或隐藏，点色块打开取色器。
  - 隐藏：填充设为完全透明（`\1a&HFF&`），描边设宽度 0，阴影设距离 0，不删除颜色标签，随时可以勾回来。
  - 显示：恢复样式的值（样式本身没有描边或阴影时用 2 像素），颜色完全透明的同时恢复为样式的不透明度（样式也透明时用不透明）。
  - 样式用了不透明底框时描边无法显示，勾选描边会响铃。
- **取色器**：就是编辑框颜色按钮用的那个，带不透明度；它的屏幕取色也能从视频画面取色，所以没有另做吸管。拖动时实时预览；预览和编辑框的颜色按钮一样，是对所选各行的一次“交互”：取色期间不能开始对比，按“取消”只撤销预览本身，期间别处做的修改不会被撤销。只写改了的部分：只改颜色时，各行原来的不透明度保持不变。
- **数字**：填充和阴影的不透明度（%，0–100）、描边宽度、阴影距离和角度、模糊，都可以拖动或输入。改距离时每行保持自己的角度（原来没有阴影时用 135°，即右下），改角度时保持距离；横纵偏移相等时写成 `\shad`。
- **背景**：只有样式能设，勾选框会把所选各行用到的样式的边框样式改为 3（不透明底框）或改回 1，一步撤销。

## 各项对应的 ASS

| 面板 | ASS |
|---|---|
| 样式 | 行的样式字段 |
| 字体 | `\fn` |
| 字重 | `\b0` 常规、`\b1` 粗体、`\b100`–`\b900` 其他字重；和 `\i` 一起显示，如“粗斜体” |
| 大小 | `\fs` |
| 对齐 | `\an`：左边三个按钮是水平方向，右边三个是垂直方向 |
| B / I / U / S | `\b`（字重 700 及以上算粗体）、`\i`、`\u`、`\s` |
| 字间距 | `\fsp`，像素 |
| 填充 | `\1c`、`\1a`；右侧是不透明度。完全透明时不勾选 |
| 描边 | `\3c`、`\3a`；右侧是 `\bord` 宽度（`\xbord`、`\ybord` 取较大的）。宽度为 0、完全透明或用不透明底框时不勾选 |
| 背景 | 样式的边框样式为 3（不透明底框）时勾选，颜色是描边颜色。只有样式能设 |
| 阴影 | `\4c`、`\4a`；`\shad` / `\xshad` / `\yshad` 换算成距离和角度：0° 向上，顺时针，135° 是右下 |
| 模糊 | `\blur` |

## 实现

- `src/style_look.{h,cpp}`：`LookAt(line, plain_pos, find_style)` 计算外观；`PlainPosition` 把编辑框的字节位置换成不算标签的字符位置。
- `src/style_edit.{h,cpp}`：修改。`SetForLine` / `SetForRange` 是纯文本的改写；`Apply` 读取选择、写入并提交，`amend_id` 用来把一次拖动合并成一步撤销。
- `src/style_panel.{h,cpp}`：面板。所有部件都是自绘的扁平控件（和视频下方的控件一样），浅色、深色都按主题取色。
  - 选择、当前行、编辑框里的选区或字幕内容变化时，等空闲时重新读一次（打字时每个键都会提交，合并成一次）。
  - `Shown()` 返回每个部件显示的内容，供测试使用。
- `src/frame_main.cpp`：`StylePanelSash` 是拖动条，`ShowStylePanel` 响应选项。
