# 字幕绑定（持久多选组）

多选至少两行，右键选择“绑定字幕”即可建立绑定组。绑定组等同于一个持久的多选集合：正常点击组内任意一行，组内所有成员都会进入和 Ctrl 多选相同的选中状态，并显示原生多选行高亮。

绑定行同时在“层”列显示组色：同组同色，不同组使用八色循环色板；层号和实际渲染层级不变。选中状态复用原生多选高亮，层列组色作为额外的持久标识保留。

## 编辑规则

组内编辑直接复用原生多选逻辑，不再单独维护“时长同步”这一套逻辑：

- 文字、样式、说话人、层、特效、注释、边距等字段按多选规则一起修改。
- 修改开始或结束时间时，全组按多选规则统一为同一个时间。
- 修改持续时间时，各成员按自己的开始时间加同样的持续时间。
- 标题栏和顶部编辑框仍以最后点击的活动行为准，但修改会作用于整组。

## 单独编辑一个成员

按住 Ctrl 或 Alt 点击绑定行，会临时只选中被点击的这一行，不展开整组。此时修改只作用于该行，用于给组内某个成员单独改文字、样式或时间。下一次正常点击其他行时恢复整组选中。

## 组关系

- 绑定已有分组的成员时，会把涉及的整组合并成一个新组。
- 复制行会保留绑定信息；复制出的行仍属于原组，可按需 Ctrl/Alt 点击后解绑。
- “解除绑定”移除选中成员；如果组内只剩一行，该行自动解除绑定。
- 绑定、解绑和组内多行编辑都支持撤销。

## 保存与兼容

绑定关系写入 ASS 附加数据，正常保存并重新打开可恢复，不需要工程文件。旧版本使用“颜色编号:随机串”格式的组标识仍可继续识别，并沿用对应的层列组色。

导出或通过不保留 ASS 附加数据的软件另存时，绑定关系可能丢失，字幕内容和时间不受影响。
