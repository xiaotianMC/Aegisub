# 字幕绑定与组颜色

多选至少两行，右键选择“绑定字幕”。在“层”列显示相同底色的字幕属于同一组，层号和实际渲染层级不变。不同组使用不同颜色，超过八组后重复使用色板。右键“解除绑定”可以移除选中成员，余下仅一行的组自动解除。

调整组内任一行的持续时间，其他成员同步增减相同毫秒数，各自开始时间保持不变。只整体平移一条字幕时不会平移整组；同一组被多选修改时只同步一次，以单独编辑行或文件中首个时长变化的成员为准。缩短受最短成员限制，防止负时长；结束时间也限制在 ASS 支持的范围内。

绑定已有分组的成员时，会合并它们原来的整组。复制字幕会保留绑定信息，复制行仍属于原组，可按需解除绑定。

绑定、解除绑定、整组时间变化均支持一次撤销。修改文字、样式和颜色不会触发时间同步。

绑定关系和颜色编号存入 ASS 附加数据，正常保存并重开可恢复，不需要工程文件。导出或通过不保留附加数据的软件另存会丢失绑定关系，但现有字幕时间不变。该功能属于桌面编辑器，没有单独的移动端数据。
