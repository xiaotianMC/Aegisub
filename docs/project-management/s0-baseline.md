## 保存中断

在基线实现上向已存在的字幕写入一部分，再从序列化器抛错。读回内容由 `complete original` 变成了 `partial replacement`，原件被替换。修复后只有显式 `Commit()` 会发布文件，写入、刷新、同步、关闭成功后才在同一目录中改名。每笔保存独占一个临时文件。普通字幕、导出、TTXT XML 和其它共用写入方已对齐这一约定。

文件系统的 28 项测试通过，覆盖序列化异常、流失败、系统文件大小限制造成的写入失败、两次保存交错、保留用户的同名旧临时文件和空文件复制。文件同步和同目录改名已经过 Linux 验证。断电后父目录条目的持久性、Windows 已打开文件/ACL 及故障恢复须另测。

### S1 窗口、编辑会话和保存

主工作台从首页进入原字幕编辑器，独立编辑窗可直接编辑。两种窗口关闭字幕时都先处理未保存内容。主窗关闭成功后回首页，独立窗关闭自身。取消、保存失败、比较页仍有选择或模型尚待恢复时，当前会话保留。全局退出、语言切换和主题重启先逐窗确认，再复核确认期间是否有新修改。

### S2 文件索引、素材登记与重启恢复

在首页选中项目，进入“项目文件”并重建索引。选择已有素材后可加入登记队列，用户在“素材登记任务”中执行、核查或取消。每个输出保留自己的标识、相对路径、文件身份、大小及 SHA-256。完成登记后，项目清单和历史随目录保存，原素材保留在原处。索引与核验在后台运行，文件和任务按每页 50 条展示。

| 情形 | 工作台行为 |
| --- | --- |
| 升级 v1 本机数据 | 使用 SQLite 备份接口复制并核查 v1，再用一个事务创建 v2 表。若备份目录不能创建，原数据库仍按 v1 可读 |
| 按项目重建索引 | 扫描先写入连接私有的临时表，再事务发布所选项目的结果。取消、写入失败或遇到另一笔较新的扫描时，保留已发布的完整索引。子项目目录、符号链接和项目内部元数据不进入父项目文件列表 |
| 任务与索引隔离 | 可重建的表只含项目文件条目和扫描状态。两个项目的位置、另一项目的索引、实际登记任务及其输出、待核查步骤和独立的测试账号引用均有回归用例 |
| 登记中断 | 在写清单前持久保存输出标识和待核查步骤。重启后按清单中的任务与输出标识核查，已写入的记录确认一次。项目位置失联或文件内容变化时保留待处理原因和原素材 |
| 取消多文件登记 | 保存取消决定。已经写入的输出和历史保留，尚未写入的文件退出登记。同一数据根的另一进程无法接管仍由活动进程处理的任务 |
| 项目和系列封面 | 可从首页选择本地 PNG 或 JPEG。工作台校验图片后按原始字节存入各自的 `.aeg/covers/`。清单使用相对路径，换封面后旧修订仍能找到旧图 |

### S3 系列分集与进度

从工作台首页选中系列，进入“系列分集”。“新建分集”使用系列模板指定的分集目录和当前项目模板。“添加已有分集”把系列目录内已有的独立项目加入清单。每集保留自己的项目资料、字幕和素材。从分集页可以打开子项目，再通过“返回系列”回到列表。

系列清单是成员关系的依据。数字集号按数值排列，特别篇等文字标签保留加入顺序。每次进入或刷新页面时，后台读取各集的手动状态。目录离线、元数据损坏或目录内 UUID 不符时，页面保留集号、登记时的集名及相对目录，标记状态未知。恢复同一个子项目后可刷新进度。添加时会核查本机已登记、可读的其他系列是否已引用相同的子项目 ID。

新建的子项目先独立落盘。若关联前发生修订冲突，可用“添加已有分集”继续。如果系列清单已经写入而本机位置事务失败，重试相同的分集会补齐位置。系列备份和历史只记录一次关联。整个系列目录移到新位置后，清单中的相对引用仍可解析；本机旧位置的重定位归 S5。
