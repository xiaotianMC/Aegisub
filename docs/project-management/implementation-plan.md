### 8.4 未来 AI 专属验证要求

本表是未来实施后的验收设计，**本轮未运行这些检查，也不将它们加入当前 T01–T18**。

| 编号 | 未来必须验证的场景和通过条件 |
| --- | --- |
| AI-V01 受控资源与批准 | 模型请求越界文件、junction/符号链接逃逸、任意 Shell/argv/URL、项目脚本或字幕内伪造授权时均不能执行；上传前确认实际目标和数据范围，批量修改/覆盖/删除确认实际影响。用户拒绝、撤回、输入/目标变化时旧批准失效，模型换工具/重复请求不能绕过 |
| AI-V02 草稿到编辑器 | 大小/编码/cue 时间/不可信 ASS 元数据校验，草稿可预览、逐项选择、拒绝/另存；应用前继续编辑/Undo/切文件/关窗/移动项目都不会误套结果。确认的内容修改正常置 dirty，拒绝或无修改保留原值，样式/Properties/Extradata、绑定和多选语义正确；一次撤销范围清楚，准备/应用失败保原内容。磁盘保存仍走原保护路径 |
| AI-V03 取消与生命周期 | 排队、运行、等待批准/审核各阶段取消后不启动下一步；本地线程安全点/进程树真正停止且 UI 不阻塞，迟到进度/结果不访问已销毁窗口或污染新会话。云端仅断开请求不能报远端已取消/零费用；应用退出不留未受控工作进程 |
| AI-V04 中断与恢复 | 文件已写而任务记录未提交、编辑已应用但记录未写、云端已受理却无回执、库不可用/输入版本变化：核查真实产物与副作用，不重复外发/计费/字幕修改。旧批准不直接重放，未知状态等待人工处理；保留有效草稿/原素材，清理只限确认归属的临时材料 |
| AI-V05 隐私与凭据 | 用非真实秘密哨兵验证 prompt/response、字幕正文、Cookie/API Key、敏感媒体/URL 不进入普通日志、进度文本、任务错误和诊断包；模型不能读下载凭据。仅发送用户选定数据；本地失败不转云端，无未经同意遥测/诊断上传。供应方数据留存/取消承诺按实际接口核验 |
| AI-V06 媒体/资源/发行 | 验证实际模型/工具、时间基与媒体格式、CPU/GPU/内存/磁盘限制、输出有效性、模型/工具许可及包形态；长任务不占满编辑线程池/播放 worker，缺能力明确错误。任务恢复、项目内草稿迁移与备份范围清楚；未承诺平台不因 AI 增首版完整支持矩阵 |

每条记录版本/commit、输入/预期/实际、包/硬件和失败限制；不在报告附真实素材、Cookie/Key、原始 prompt/response 或字幕正文。模型质量与系统安全分别评价：一次生成成功不能证明授权、恢复或草稿应用安全。受影响的原编辑/下载用例需回归，但 AI 专属用例不是当前首版的额外完成条件。

### 8.5 适用记录

本次核对以 PRD 1.0、D01–D03 和 `60f96f7ac` 的既有源码证据为依据。现有转录的本地、云端、外部程序入口及系统密钥封装见架构第 14.1 节。AI-P0–P3 与 AI-V01–V06 专指新增工作台任务和草稿接入。Windows 包、站点登录、项目数据迁移及未来 AI 验收均待相应阶段取得运行证据。
