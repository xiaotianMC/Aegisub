# 反向移动路径

在字幕列表中右键点击带 `\move` 的字幕行，选择“反向移动路径”。起点和终点立即交换，运动时间、字幕起止时间、文字和其他效果保持不变。再次点击恢复原路径，Ctrl+Z 可撤销。

支持四参数和六参数形式，以及负数和小数坐标。例如 `\move(100,200,500,200,300,1500)` 变为 `\move(500,200,100,200,300,1500)`。

每次只修改右键所指的活动行。同一行含多个顶层 move 标签时，会一并反向；没有 move 的行不启用此命令。变换标签内部的嵌套内容不作改动。动画的其他属性不倒放。

结果随标准 ASS 文本保存，不增加额外配置或数据存储；其他支持 ASS 的播放器和编辑器可直接使用。该入口属于桌面版，不存在单独的移动端数据。

开发验证：`python tests/data/check_reversed_move.py <原始ASS> <保存的ASS> <反向的行号...>`，省略行号时验证与原始字幕一致，用于检查再次反向或撤销的结果。
