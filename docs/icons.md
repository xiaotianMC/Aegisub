# 图标与工具栏

图标仍是 Aegisub 原有的图（`src/bitmaps/button`，每个 16 / 24 / 32 / 48 / 64 五种尺寸，源文件在 `docs/art-sources/buttons`），没有换成其他图标集。本版改的是它们在深色外观下的显示、绘图形状图标，以及主工具栏的排列。

## 深色外观下的图标

原图是给浅色背景画的：粗体、斜体、播放、箭头这类黑色字形，以及部分图标里的黑色部件，在深色背景上几乎看不见。深色外观下加载图标时自动调整（`src/libresrc/libresrc.cpp`）：

- **字形图标**（最大尺寸那张里九成左右的像素是深色，例如 B / I / U / S、fn、播放 / 暂停 / 停止、上下箭头、撤销 / 重做、删除、visual_standard）：所有深色像素按亮度反转，色相不变——黑变浅灰，深蓝变浅蓝。
- **其他图标**：只提亮**接近黑色、接近灰色、并且连到图标边缘**的部分，例如 AB 颜色按钮里的黑色 B、锤子头、音符、黑色描边。彩色部分不动；画在浅色部件上面的黑色记号（放大镜里的加号）也不动，保持原有对比。
- 同一个图标的各个尺寸按同一结论处理；结果按（图标、尺寸、方向、深浅）缓存。

切换外观时，工具栏（主、音频、视频、可视化工具）、编辑框的格式按钮和音视频的开关按钮会立即换图标。菜单里的图标和已经打开的可视化工具子工具栏要等重新打开或重启。

为什么不用 SVG 渲染：试过用 wxWidgets 自带的 nanosvg 渲染原 SVG，大尺寸和 PNG 差不多，但 16px 明显比原 PNG 模糊（原 PNG 是对齐像素导出的）。现有五种尺寸已覆盖常见缩放，所以保留 PNG。

## 绘图形状图标

矩形、椭圆、三角形、多边形四个图标原来是代码画在白底上再抠掉白色，边缘有锯齿，高分屏下发虚。现在按原 `visual_rectangle` 图标的样式（蓝色填充、深色描边）用 SVG 生成，任意缩放都清晰，背景透明；右下角的小三角表示长按可以选形状，深色外观下改用浅色描边和小三角。

## 主工具栏

默认的主工具栏从 27 个按钮减到 15 个：常用按钮保持原样，打开对话框的按钮收进下拉按钮。

| 组 | 按钮 | 下拉菜单 |
|---|---|---|
| 文件 | 新建、打开、保存 | |
| 视频 | 跳转到（下拉）、放大、缩小 | 跳转到（帧或时间）、视频跳到当前行开始、视频跳到当前行结束 |
| 时间 | 起点对齐视频、终点对齐视频、选中可见行、对齐场景、平移到当前帧 | |
| 字幕 | 样式管理器（下拉） | 样式管理器、属性、附件、字体收集器、自动化 |
| 工具 | 平移时间（下拉） | 平移时间、样式助手、翻译助手、分辨率重采样、时间后处理、汉字计时、拼写检查 |
| 其他 | 选项、标签显示切换 | |

- 下拉按钮本身执行组里的第一个命令（固定，不随上次选择变），点箭头打开菜单；菜单打开时按当前状态启用或禁用各项，和菜单栏一致。
- **首选项 → 常规 → 经典主工具栏（显示全部按钮）**（`App/Classic Toolbar`）恢复原来的 27 个按钮，切换立即生效。
- 工具栏布局在 `src/libresrc/default_toolbar.json`：`main` 是分组布局，`main/classic` 是原布局；列表里写一个数组表示一个下拉按钮。
- 命令面板（`docs/command-palette.md`）可以找到所有命令，包括不在工具栏上的。

音频、视频、可视化工具三个工具栏只换了深色图标，排列不变。

## 测试

- `ordinary_edit.dark_appearance_lightens_dark_icons_and_keeps_coloured_ones`：深色下粗体图标变亮；保存图标大部分像素不变；放大镜里的加号保持深色；调整规则在人工图像上的效果；编辑框按钮随外观立即换图；形状图标透明背景、按请求尺寸生成。
- `ordinary_edit.main_toolbar_groups_dialogs_in_dropdowns_and_has_a_classic_layout`：分组布局 15 个按钮、3 个下拉、菜单共 15 项；打开下拉时按状态禁用；经典布局 27 个按钮、无下拉；切换外观后重建。

离屏截图检查过浅色 / 深色下的分组与经典工具栏、编辑框格式按钮、形状图标；另用 Python 把全部 122 个图标调整前后的效果排在深色底上逐个看过。临时测试没有保留。
