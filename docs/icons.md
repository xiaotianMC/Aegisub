# 图标与工具栏

图标默认是本版重绘的单色图标；Aegisub 原有的彩色图标（`src/bitmaps/button`，每个 16 / 24 / 32 / 48 / 64 五种尺寸，源文件在 `docs/art-sources/buttons`）仍可在首选项里换回。本版还改了原图在深色外观下的显示、绘图形状图标，以及主工具栏的排列。

## 单色图标

`src/bitmaps/button` 里的全部 122 个图标，加上绘图工具的四种形状和样式面板的六个对齐按钮，共 132 个单色线条图标：四个工具栏、可视化子工具（矢量裁剪的 8 个子工具、`\move` / `\pos` 切换）、编辑框的格式和颜色按钮、样式管理器的排序箭头、取色器、卡拉 OK 分割按钮、样式面板，以及菜单里的图标。只有程序本身的图标（`misc/wxicon`）和关于对话框的图片不变。

- **来源**：通用的 71 个直接用 [Lucide](https://lucide.dev)（ISC 许可，部分源自 Feather，MIT 许可；声明在 `src/libresrc/LICENSE.lucide`，`LICENCE` 和 Windows 安装包的许可证里也有）：文件、编辑、查找、播放控制、缩放、设置、帮助、箭头、斜体 / 下划线 / 删除线、裁剪、移动、旋转、链接、筛选、对齐等；另有 5 个菜单图标（关闭 / 保存关键帧、时间码，关闭视频）是 Lucide 主体缩小放左上，右下角加 × 或保存箭头。其余 56 个是 Aegisub 特有的（音频播放范围、对齐场景、平移到当前帧、矢量裁剪子工具、形状、AB 颜色按钮、fn、粗体、频谱、上下对齐等），按 Lucide 的规范自绘。
  - 在 16px 下细节挤成一团的 Lucide 图标换成自绘：粗体（Lucide 的太细，区分不出加粗）、频谱、3D 旋转、矢量裁剪、查找替换、无视频。
  - 播放、暂停、停止、上一个、下一个改为实心，和自绘的音频播放图标一致。
  - Lucide 用零长度线段画点（信息的 i、对话气泡、键盘），nanosvg 不画；生成时改成实心小圆，16px 下画成整像素的小方点。
- **画法**：Lucide 的 24×24 网格，线宽 2，圆头圆角，圆角半径 2（小部件 1），四周留 2。每个图标是一段 SVG（`src/libresrc/icons_modern.cpp`，按名称排序，名称就是原 PNG 的名称），`@` 处填入颜色，路径全部是绝对坐标。
- **生成**：`tools/icons/generate.py <lucide-static 的 icons 目录>` 生成 `icons_modern.cpp`；Lucide 的映射、组合图标和自绘图标都在这个脚本里，改图标改它。脚本里的 `Hinter` 和 C++ 的像素对齐算法相同，可用来出预览。
- **颜色**：浅色外观 `#2b2b2b`，深色外观 `#d8d8d8`，只有这一种颜色；开关类按钮（自动提交、自动滚动、频谱等）的开启状态由工具栏的按下底色表示，图标本身不变。
- **加载**：`GETBUNDLE` / `GETBUNDLEDIR` 和命令的 `CMD_ICON` 把图标名称传给 `libresrc_getbitmapbundle`；有单色版本就用 wxWidgets 的 SVG 渲染（nanosvg）生成，任意缩放都清晰，否则用原 PNG。从右到左的界面里整幅镜像。结果按（图标、尺寸、方向、深浅、风格）缓存。
- **颜色按钮**：主要、次要、边框、阴影四个颜色按钮都是“AB”，分别标出 A 下的色条、B 下的色条、空心长条、带偏移阴影和实心长条。
- **绘图形状**：矩形、椭圆、三角形、多边形是同样风格的线条，右下角的实心小三角表示长按可选形状。
- **切换**：**首选项 → 常规 → 经典彩色图标**（`App/Classic Icons`）换回原图标，和切换外观一样立即重建工具栏和编辑框按钮。
- **像素对齐**：每个尺寸单独生成（`libresrc.cpp` 的 `ModernBundle`），不是一张 SVG 缩放。线宽取整数像素：16px（100%）1px，20、24px（125%、150%）2px，32px（200%）3px，即约 1.25 倍缩放系数四舍五入。坐标挪动不到一个像素，落在像素网格上：奇数线宽的线心在像素中心，偶数线宽在像素边上；圆和圆角矩形按外边对齐，实心矩形按边对齐；曲线的控制点跟着所属端点移动；离上一点不到 0.75 的点（小勾、短线）跟着上一点移动，不会消失或变长；实心小圆（点）取整像素直径，2px 以内画成方点。自带线宽的部分（粗体 B、边框色按钮的空心条）也取整像素，比普通线条粗或细至少一像素。
  - 原因：按 1.5 线宽直接缩放时，100% 下每条线落在两列像素之间，变成两列半透明的灰，在 Windows 上和对齐像素的系统文字、图标放在一起明显发虚、偏灰。Linux 上常用 200% 缩放或文字本身较软，不太明显。
  - 125%、150% 这类非整数缩放下网格对不齐所有点，斜线和圆弧仍有抗锯齿，横竖线是实的。
- **测试**：`ordinary_edit.icons_are_monochrome_in_the_appearance_colour_unless_classic` 检查各工具栏、编辑框和菜单命令都是单色、两种外观的颜色、16 / 20 / 24 / 32px 下半透明像素的比例和线宽、Lucide 的点画成方点、从右到左镜像、形状的角标，以及经典图标的切换。

## 深色外观下的原图标

原图是给浅色背景画的：粗体、斜体、播放、箭头这类黑色字形，以及部分图标里的黑色部件，在深色背景上几乎看不见。深色外观下加载图标时自动调整（`src/libresrc/libresrc.cpp`）：

- **字形图标**（最大尺寸那张里九成左右的像素是深色，例如 B / I / U / S、fn、播放 / 暂停 / 停止、上下箭头、撤销 / 重做、删除、visual_standard）：所有深色像素按亮度反转，色相不变——黑变浅灰，深蓝变浅蓝。
- **其他图标**：只提亮**接近黑色、接近灰色、并且连到图标边缘**的部分，例如 AB 颜色按钮里的黑色 B、锤子头、音符、黑色描边。彩色部分不动；画在浅色部件上面的黑色记号（放大镜里的加号）也不动，保持原有对比。
- 同一个图标的各个尺寸按同一结论处理；结果按（图标、尺寸、方向、深浅）缓存。

切换外观时，工具栏（主、音频、视频、可视化工具）、编辑框的格式按钮和音视频的开关按钮会立即换图标。菜单里的图标和已经打开的可视化工具子工具栏要等重新打开或重启。

为什么不用 SVG 渲染：试过用 wxWidgets 自带的 nanosvg 渲染原 SVG，大尺寸和 PNG 差不多，但 16px 明显比原 PNG 模糊（原 PNG 是对齐像素导出的）。现有五种尺寸已覆盖常见缩放，所以保留 PNG。

## 经典图标下的绘图形状图标

矩形、椭圆、三角形、多边形四个图标原来是代码画在白底上再抠掉白色，边缘有锯齿，高分屏下发虚。现在按原 `visual_rectangle` 图标的样式（蓝色填充、深色描边）用 SVG 生成，任意缩放都清晰，背景透明；右下角的小三角表示长按可以选形状，深色外观下改用浅色描边和小三角。

## 主工具栏

默认的主工具栏从 27 个按钮减到 13 个：常用按钮保持原样，打开对话框的按钮收进下拉按钮。

| 组 | 按钮 | 下拉菜单 |
|---|---|---|
| 文件 | 新建、打开、保存 | |
| 视频 | 跳转到（下拉） | 跳转到（帧或时间）、视频跳到当前行开始、视频跳到当前行结束 |
| 时间 | 起点对齐视频、终点对齐视频、选中可见行、对齐场景、平移到当前帧 | |
| 字幕 | 样式管理器（下拉） | 样式管理器、属性、附件、字体收集器、自动化 |
| 工具 | 平移时间（下拉） | 平移时间、样式助手、翻译助手、分辨率重采样、时间后处理、汉字计时、拼写检查 |
| 其他 | 选项、标签显示切换 | |

- 下拉按钮本身执行组里的第一个命令（固定，不随上次选择变），点箭头打开菜单；菜单打开时按当前状态启用或禁用各项，和菜单栏一致。
- **首选项 → 常规 → 经典主工具栏（显示全部按钮）**（`App/Classic Toolbar`）恢复原来的 27 个按钮，切换立即生效。
- 工具栏布局在 `src/libresrc/default_toolbar.json`：`main` 是分组布局，`main/classic` 是原布局；列表里写一个数组表示一个下拉按钮。
- 命令面板（`docs/command-palette.md`）可以找到所有命令，包括不在工具栏上的。

音频、可视化工具两个工具栏换了图标，排列不变。视频下方的工具栏去掉了停止按钮（播放按钮兼作暂停），自动滚动开关分到右边一组；放大、缩小移到视频下方的缩放控件（见 [主界面](main-window.md#视频进度条与下方控件)）。

## 测试

- `ordinary_edit.icons_are_monochrome_in_the_appearance_colour_unless_classic`：见上文“单色图标”。
- `ordinary_edit.dark_appearance_lightens_dark_icons_and_keeps_coloured_ones`（在经典图标下）：深色下粗体图标变亮；保存图标大部分像素不变；放大镜里的加号保持深色；调整规则在人工图像上的效果；编辑框按钮随外观立即换图；形状图标透明背景、按请求尺寸生成。
- `ordinary_edit.main_toolbar_groups_dialogs_in_dropdowns_and_has_a_classic_layout`：分组布局 13 个按钮、3 个下拉、菜单共 15 项；打开下拉时按状态禁用；经典布局 27 个按钮、无下拉；切换外观后重建。

离屏截图检查过浅色 / 深色下的分组与经典工具栏、编辑框格式按钮、形状图标；另用 Python 把全部 122 个图标调整前后的效果排在深色底上逐个看过。临时测试没有保留。
