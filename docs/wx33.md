# 升级到 wxWidgets 3.3

内置的 wxWidgets 从“跟随 3.2 分支”改为固定的 **v3.3.4**（`subprojects/wxWidgets.wrap`）。

## 影响哪些构建

| 构建 | 用的 wx |
|---|---|
| Windows（MSVC，CI 和本地） | 内置，3.3.4（Windows 没有系统 wx，总是用内置） |
| macOS 打包版（CI 强制内置） | 内置，3.3.4 |
| Linux、macOS 用系统 wx 的构建 | 系统 wx 至少 3.3.4 时用系统版本，否则自动改用内置 3.3.4 |

最低版本（`meson_options.txt` 的 `wx_version`）也是 3.3.4。Ubuntu 等发行版目前只有 3.2 的软件包，所以 Linux 上一般会用内置 wx 构建：需要 CMake，首次构建要多编译 wx 本身。CI 的 Ubuntu 任务安装的 `libwxgtk3.2-dev` 因此不再被使用。代码本身仍能用 3.2 编译（3.3 才有的功能用 `wxCHECK_VERSION(3, 3, 0)` 隔开），需要时可以把 `-Dwx_version=3.2.2` 传给 meson。

之前的“3.2”是分支名，每次重新下载都会拿到 3.2 分支的最新提交（目前在 3.2.12 之后），所以不同时间构建的 Windows 版本 wx 小版本不同。现在固定为发布标签，构建结果可以复现。

## 构建配置的改动

- **关闭 WebP**（`wxUSE_LIBWEBP=OFF`）：3.3 新增的 WebP 解码自带的静态库不是位置无关代码，内置 wx 以共享库构建时（Linux 默认）无法链接。最低版本提到 3.3.4 后，Linux 上默认就走这条路，所以这一项是必需的。Aegisub 只注册 PNG 解码，和已经关闭的 TIFF 一样用不到。构建时若仍生成了 `webp` 目标会直接报错。
- **libpng 冲突**：上游在 #399 里记录过“新 wx + 新 libpng 在 Windows 上启动即崩溃”，原因是同一个程序里链接了两份 libpng（wx 自带一份，freetype / libass 用另一份）。本分支的上游代码（#659 “share libpng and zlib with wxWidgets”）已经让内置字体组件关闭 PNG，wx 使用自带的唯一一份；使用系统 libass 时 wx 改用系统 libpng。所以不需要像 arch1t3cht 的 3.3 测试分支那样降级 libpng。**这一点需要在 Windows 上实际启动确认。**
- 上游为 3.2.11 / 3.3.4 起 `wxGridBagSizer` 行为变化做的补偿（自动化脚本对话框的行高）已经在本分支里。

## Windows 深色模式

开关就是原有的 **首选项 → 界面 → 外观 → 主题**（跟随系统 / 浅色 / 深色）。用 3.3 构建后：

- 选“深色”，或“跟随系统”且系统是深色时，启动时调用 `MSWEnableDarkMode`，菜单、对话框、输入框、滚动条等原生控件一起变深。
- 原生控件只在启动时决定深浅，运行中改主题要重启才完全生效（首选项里有说明）；自绘部分立即切换。
- 深色下 Windows 仍把凹陷 / 凸起边框画成浅色，所以原生深色生效时，字幕网格、编辑框、音频区、卡拉 OK 条、开关按钮、样式预览、进度窗口、取色器的边框改为平边框（`theme::Border`）。做法参考了 arch1t3cht 的 3.3 测试分支。
- 启动页跟随外观：深色时用深色配色，标题栏也请求系统画成深色。

## 验证

- Linux，内置 wx 3.3.4（与 Windows 相同的源码和选项，以共享库方式构建，`--force-fallback-for=wxWidgets`）：完整构建成功，没有新的弃用警告；`gtest main`、`luajit-52`、对比集成、模型权限 4 个套件全部通过；界面测试 211 项逐个隔离运行，35 项失败，全部在 3.2 下的 38 项环境相关基线之内，没有新增失败，另有 3 项网格选择测试在 3.3 下通过。
- Linux，系统 wx 3.2.9（`build/`，配置于最低版本提高之前）：重新编译，外观、首选项搜索、状态栏、工具栏测试通过。
- Windows x64 Release（另一台机器，合并前）：wx 3.3.4 静态构建，205 项编辑器集成测试通过，启动确认原生深色和深色标题栏生效。
- 启动页的浅色和深色用离屏截图检查过。
- **Windows 和 macOS 没有在这里构建**：MSVC 编译、启动（libpng）、原生深色效果、平边框、启动页深色都需要在 Windows 上确认。
